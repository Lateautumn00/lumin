> 规格：`docs/spec/disk-analyzer.md` · 自动化：`apps/desktop/e2e/disk-analyzer-smoke.spec.ts`

## 2. R2 八类异常逐条

| 类别             | 场景与验证                                                                                                                                                                       | 结果   |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| 1. 中文/空格路径 | 单测 `scan.worker.test.ts`：目录 `作业 资料`、文件 `试卷 一.txt` / `根 文件.txt` 正常聚合（大小 6 B、目录数 1）；e2e 临时目录名保持 ASCII（本机 Node 对非 ASCII 目录名会硬崩，已知环境限制），文件名可含中文 | 通过   |
| 2. 文件被占用     | 工具只 `stat` 元数据、不打开文件内容，共享/独占占用不影响统计；`stat` 或子目录 `readdir` 失败计入 `skipped` 不中断（单测 `aggregateDirectory` 缺失目录 → `skipped=1`）；根目录不可读 → `DA_ROOT_INVALID` | 通过   |
| 3. 加密文件       | 不适用：不读取文件内容，加密文件按卷上元数据大小正常计入，不产生解密分支                                                                                                            | 不适用 |
| 4. 超大文件       | 无单文件大小上限（仅 `stat`，开销恒定）；单测 `runScan` 注入 `maxFiles=1`，2 个文件 → `DA_TOO_MANY_FILES`；实际单次上限 200,000 文件                                                        | 通过   |
| 5. 任务取消       | `scan` 走壳 `runTask` 三段式，取消由 `lumin:task:cancel` → worker `terminate`；UI 加载态「取消」同通道；本工具未单列 e2e 取消用例（同一 `runTask` 路径已由 duplicate-finder e2e 取消用例验证），取消后无落盘残留（只读无产物） | 通过   |
| 6. 并发溢出       | 工具无批处理，并发扫描由壳任务队列上限协调；每次扫描独立 worker 与计数，互不共享状态                                                                                                | 通过   |
| 7. 磁盘满         | 不适用：只读工具，全程不写盘，无磁盘空间依赖                                                                                                                                        | 不适用 |
| 8. 断电恢复       | 不适用写盘原子性；扫描为纯读操作，强杀无中间产物，重启后可对同一目录重新扫描（无脏状态）                                                                                            | 通过   |

## 3. 不可实测项说明

- **真实文件占用**：本工具只 `stat`，Windows 共享读/独占写均不影响；占用语义不构成失败分支，故不构造真实 EBUSY。
- **磁盘满 / 断电恢复**：无写盘路径，按「不适用」记录；如需强制验证，可断言扫描前后目录 mtime/hash 不变（e2e 已隐式保证只读）。
- **中文目录名**：本机 Node `fs` 对非 ASCII 临时目录名存在环境级硬崩（duplicate-finder 亦记录），e2e 目录名用 ASCII；中文文件名与子目录名由单测覆盖。

## 5. 设置记忆

- 键：`tools.disk-analyzer.lastRoot`（空串清空记忆）、`tools.disk-analyzer.minFileBytes`（默认 0）。
- 单测 `node.test.ts` 覆盖缺省回落、非法存量归一、`set-config` 保留/清空目录；e2e 经 IPC 预置目录后重进页面回填。
- 执行 `scan` 时同步记忆本次目录与阈值（不阻塞扫描失败返回）。

## 6. 只读保证

- worker 仅调用 `readdir` / `stat`，无 `writeFile` / `rename` / `unlink` / `rm` 调用；renderer 只发 `scan` 与展示。
- e2e 用例结束仅清理测试用临时目录（测试自身行为），工具链路不产生任何文件。
