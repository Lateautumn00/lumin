# 计算器 — 字段级功能清单（M1 验收附件，M36 增阶乘与进制）

> 依据 AGENTS §11：开工前定稿。变更须同步更新本文件与 `docs/opencode/plan.md` §4.1 / §4.36。

## 1. 输入项

| 字段     | 类型                      | 约束                                                                                | 默认值         |
| -------- | ------------------------- | ----------------------------------------------------------------------------------- | -------------- |
| 表达式   | string                    | 键盘全量输入；允许数字、`+ - × ÷ * / % ^ ( ) . !`、函数名、`pi`/`e`；空表达式不计算 | `''`           |
| 角度模式 | `'deg' \| 'rad'`          | 影响 `sin/cos/tan/asin/acos/atan` 输入输出                                          | `'deg'`        |
| 布局档位 | `'basic' \| 'scientific'` | 仅影响按钮集，不影响表达式能力                                                      | `'scientific'` |
| 历史     | `{ expr, result, at }[]`  | localStorage 持久化，上限 100 条（超限丢最旧）                                      | `[]`           |
| 页签     | `'calc' \| 'base'`        | 计算 / 进制；计算页签保留原布局，进制页签为纯 renderer 换算                         | `'calc'`       |
| 进制数值 | string                    | 仅整数（可带正负号），十进制 ≤512 字符；空 → 空态                                   | `''`           |
| 输入进制 | `2 \| 8 \| 10 \| 16`      | 与数值共同决定解析基数；十六进制输入不区分大小写                                    | `10`           |

## 3. 计算与错误分支

求值纯函数 `evaluate(expr, angleMode)` → `{ ok: true, value: number } | { ok: false, error }`。
求值基于 **`mathjs/number` 精简入口**（官方减重导出；无单位/矩阵/复数，`sqrt(-1)` → NaN 归入 NON_FINITE）。

| 分支       | 条件                                                    | 错误码           | 中文文案               |
| ---------- | ------------------------------------------------------- | ---------------- | ---------------------- |
| 空表达式   | `trim() === ''`                                         | `EMPTY_EXPR`     | 请输入表达式           |
| 语法错误   | mathjs parse 抛错                                       | `SYNTAX_ERROR`   | 表达式语法无效         |
| 未知符号   | 白名单外符号/节点，或求值期 `Undefined symbol`          | `UNKNOWN_SYMBOL` | 表达式含未知符号       |
| 非数值结果 | 求值返回 boolean/字符串（防御分支，白名单后实际不可达） | `NON_NUMERIC`    | 结果不是数值           |
| 非有限结果 | `!Number.isFinite(value)`（如 1/0、溢出、`sqrt(-1)`）   | `NON_FINITE`     | 结果无效（除零或溢出） |
| 求值异常   | 其他抛出                                                | `EVAL_FAILED`    | 计算失败               |
| 阶乘定义域 | `factorial(x)` / `x!` 且 x 非非负整数                   | `EVAL_FAILED`    | 阶乘仅支持非负整数     |

安全模型：**AST 白名单先行**（节点类型 + 符号 + 运算符三重校验），白名单外表达式不进入求值。

支持的函数与常量（scope 白名单，其余一律不可见）：
`sin cos tan asin acos atan ln log log10 sqrt abs round floor ceil factorial`、常量 `pi e`。
`^` 幂、括号嵌套、四则运算与 `%`（取模，mathjs 语义）。
阶乘支持 `factorial(n)` 与后缀 `n!` 两种写法（AST 归一后统一走本地非负整数实现，0! = 1，171! 溢出 → `NON_FINITE`）。

### 3.1 进制换算（`src/calc/base.ts`，纯函数）

`convertBase(input, radix)` → `{ ok: true, value: { binary, octal, decimal, hex } } | { ok: false, error }`。
使用 BigInt 解析与 toString(radix)，**超过 2^53 的大整数不丢精度**；负数带前导 `-`；输出十六进制为小写。

| 分支     | 条件                     | 错误码               | 中文文案                       |
| -------- | ------------------------ | -------------------- | ------------------------------ |
| 空输入   | `trim() === ''`          | `BASE_EMPTY`         | 请输入要转换的数值             |
| 超长     | 字符数 > 512             | `BASE_TOO_LONG`      | 输入超过 512 个字符            |
| 小数     | 含 `.`                   | `BASE_NOT_INTEGER`   | 进制转换仅支持整数，不支持小数 |
| 非法字符 | 字符不在当前进制字符集内 | `BASE_INVALID_DIGIT` | 字符「x」不属于 N 进制         |

## 4. 历史交互

| 操作         | 行为                                                                  |
| ------------ | --------------------------------------------------------------------- |
| 计算成功     | 追加 `{ expr, result, at: Date.now() }`；与上一条完全相同则不重复追加 |
| 点击历史条目 | 表达式回填为该条 `expr`（不自动计算）                                 |
| 清空历史     | 确认后删除全部（一次 `NPopconfirm`）                                  |
| 超限         | 丢弃最旧一条，保持 100                                                |

## 5. 三态（R4）

| 状态   | 呈现                                                                              |
| ------ | --------------------------------------------------------------------------------- |
| 空态   | 首屏即输入区 + 引导文案「输入表达式，Enter 计算」；历史空态「暂无历史记录」       |
| 加载态 | N/A（纯同步计算，无长任务）——本工具声明豁免                                       |
| 报错态 | 结果区行内红字显示错误文案，保留表达式供修改，无独立重试按钮（改完 Enter 即重试） |

## 6. 验收

- `evaluate` 纯函数单测覆盖 **≥80%**（plan.md §4.1）
- M36 增补：阶乘（`factorial(5)`/`5!`/`0!`、负数与非整数 → `EVAL_FAILED`、171! → `NON_FINITE`）、进制（四进制互转、负数、超 2^53、全部错误分支）单测
- 键盘 + 按钮双通道可完成全部按钮集操作
- 进制页签：输入即实时输出四种进制，复制按钮回显「已复制」，非法输入行内报错
- 历史 100 条上限与持久化（刷新后仍在）
- 门禁全绿
- **chunk 实测（M1 记录，R5 口径 gzip）**：计算器专属增量 = `calculator-*` + 独占 `number-*`（mathjs/number 拆分）= **1,001,008 B raw / 219,463 B gzip（977.6KB / 214.3KB）**，较 mathjs 全量入口约 -44%。**R5 已修订（2026-11-13）**：求值类工具例外上限 300KB gzip（AGENTS §8 / plan.md R5），本工具达标。根因：mathjs 公开入口 `parse` 位于 side-effectful 聚合器（连带 algebra/help/embeddedDocs），官方无更小公开入口，按 Q13 不换库。
