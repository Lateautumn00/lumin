# folder-compare（文件夹对比）冒烟记录

> 工具：`folder-compare`（M24，2026-11-20）
> 规格：`docs/spec/folder-compare.md` · 自动化：`apps/desktop/e2e/folder-compare-smoke.spec.ts`
> 手工复现环境：Windows x64 · Electron 壳 · 本地离线 · 纯 `node:fs`（零新增依赖）
> 结论：只读工具（不读文件内容、不写盘、不改删文件）；八类异常均有覆盖路径或明确不适用说明；配对口径、时间容差、大小写不敏感与截断由单测 + e2e 双覆盖。

## 2. R2 八类异常逐条

| 类别             | 场景与验证                                                                                                                                                                                     | 结果   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| 1. 中文/空格路径 | 单测 `compare.worker.test.ts`：左右均含 `作业 资料/试卷 一.txt`（同大小同 mtime）→ 单条 `same`、相对路径保留中文与空格；e2e 临时目录名保持 ASCII（本机 Node 对非 ASCII 目录名会硬崩，已知环境限制） | 通过   |
| 2. 文件被占用     | 工具只 `stat` 元数据、不打开文件内容；共享/独占占用不影响比较；`stat` 或子目录 `readdir` 失败计入 `skipped` 不中断；根目录不可读 → `FC_ROOT_INVALID`（detail 标侧别）                              | 通过   |
| 3. 加密文件       | 不适用：不读取文件内容，加密文件按卷上元数据（大小/时间）正常参与比较，不产生解密分支                                                                                                            | 不适用 |
| 4. 超大文件       | 无单文件大小上限（仅 `stat`，开销恒定）；单侧普通文件 200,000 上限，单测注入 `maxFiles=1` + 2 文件 → `FC_TOO_MANY_FILES`（detail 含「左侧」）；结果 2 万条上限由单测注入验证 `truncated` 计数       | 通过   |
| 5. 任务取消       | `compare` 走壳 `runTask` 三段式，取消由 `lumin:task:cancel` → worker `terminate`；UI 加载态「取消」同通道；只读无产物，取消后无落盘残留（同一 `runTask` 路径已由 duplicate-finder e2e 取消用例验证） | 通过   |
| 6. 并发溢出       | 工具无批处理，并发对比由壳任务队列上限协调；每次任务独立 worker 与两侧 Map，互不共享状态                                                                                                        | 通过   |
| 7. 磁盘满         | 不适用：只读工具，全程不写盘，无磁盘空间依赖                                                                                                                                                     | 不适用 |
| 8. 断电恢复       | 不适用写盘原子性；对比为纯读操作，强杀无中间产物，重启后可对同一对目录重新对比（无脏状态）                                                                                                       | 通过   |

## 3. 不可实测项说明

- **真实文件占用**：本工具只 `stat`，Windows 共享读/独占写均不影响；占用语义不构成失败分支，故不构造真实 EBUSY。
- **磁盘满 / 断电恢复**：无写盘路径，按「不适用」记录；只读性由 e2e 结束仅清理测试自建临时目录隐式保证。
- **目录读取失败计入 skipped**：Windows 下难以稳定构造「可 stat 根目录但子目录 readdir 失败」的环境（需 ACL 隔离），按代码路径 + `FC_ROOT_INVALID` 用例覆盖，记录为已知环境限制。
- **中文目录名**：本机 Node `fs` 对非 ASCII 临时目录名存在环境级硬崩（duplicate-finder / disk-analyzer 亦记录），e2e 目录名用 ASCII；中文文件名与子目录名由单测覆盖。

## 5. 设置记忆

- 键：`tools.folder-compare.leftRoot` / `rightRoot`（空串清空为 null）、`compareMtime`（默认 `true`）。
- 单测 `node.test.ts` 覆盖缺省回落、非法存量归一、`set-config` 省略目录保留上次 / 空串清空；e2e 经 IPC 预置目录后重进页面回填。
- 执行 `compare` 时同步记忆本次左右目录与开关（不阻塞对比失败返回）。

## 6. 只读保证与比较口径声明

- worker 仅调用 `readdir` / `stat`，无 `writeFile` / `rename` / `unlink` / `rm` 调用；renderer 只发 `compare` 与展示。
- 仅比较文件元数据（大小 + 修改时间，容差 2s）：**不读取文件内容、不计算哈希**；「相同」不代表逐字节一致，UI 已明示；内容级判断请使用 `file-hasher` / `duplicate-finder`。
- 目录仅用于遍历，不单独参与配对（空目录差异不展示）。
