## 2. R2 八类异常逐条

| 类别             | 场景与验证                                                                                                                                                                                                               | 结果   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| 1. 中文/空格路径 | 用例 1：输入 `照片 1.png`、输出目录 `输出 目录`、产物 `照片 1_去水印.png` 与 `照片 1_去水印 (1).png` 全链路可读写；单测 `contract.test.ts` 断言命名模板与扩展名保留                                                      | 通过   |
| 2. 文件被占用    | 单测 `node.test.ts`：`checkExclusive` 抛 `EBUSY` → `IDW_FILE_LOCKED`；`statSize` 抛 `EACCES` → `IDW_FILE_LOCKED`；`checkReadable` 抛 `ENOENT` → `IDW_INPUT_INVALID`；e2e 未构造真实独占（图片查看器通常共享读）          | 通过   |
| 3. 加密文件      | 不适用（位图无解密语义）；伪装 `.png` 的损坏/加密容器走解码失败 → `IDW_IMAGE_CORRUPT`（用例 2 直达 worker 断言 + 单测 `dewatermark.worker.test.ts`）                                                                     | 不适用 |
| 4. 超大文件      | 用例 2：41MB → renderer 预检跳过并提示；单测 `node.test.ts`：`statSize > 40MB` → `IDW_IMAGE_TOO_LARGE`；单测 worker：解码尺寸 >10000 → `IDW_IMAGE_TOO_LARGE`、0×0 → `IDW_IMAGE_CORRUPT`                                  | 通过   |
| 5. 任务取消      | 用例 2：提交 2000×2000 图的大区域任务后立即 `lumin:task:cancel` → `CANCELLED` 事件；输出目录无 `.tmp`；UI 加载态走 `TaskProgress` 同通道取消                                                                             | 通过   |
| 6. 并发溢出      | 区域上限 20（`schema.test.ts` 拒绝第 21 个）；同名输出 `(1)`… 递增（e2e + worker 单测）；多任务并发由壳队列 `taskConcurrency` 与 `maxPending` 统一控制，溢出返回壳级 `QUEUE_FULL`（壳级 e2e 覆盖，本工具不新增并发语义） | 通过   |
| 7. 磁盘满        | 单测 worker：输出目录被同名文件占位 → `IDW_WRITE_FAILED`；编码后输出目录被移除 → `IDW_WRITE_FAILED`；写盘为 `.tmp` + rename，失败 best-effort 清理临时文件；未做 ENOSPC 定向实测（说明见 §3）                            | 通过   |
| 8. 断电恢复      | `.tmp` + rename 保证目标文件要么不存在要么完整；解码/编码/写入失败与取消均不产生半成品（单测 + 用例 2）；e2e 未强杀（说明见 §3）                                                                                         | 通过   |

## 3. 不可实测项说明

- **真实文件占用**：Windows 图片查看器以共享读打开，稳定制造 EBUSY 成本高；占用映射由单测覆盖同一代码路径（`classifyInputError`）。
- **磁盘满**：未建 VHD 定向模拟 ENOSPC；写失败分支由「输出目录被文件占位」与「编码后目录被删」两条单测覆盖（同一 `IDW_WRITE_FAILED` 映射）。
- **断电恢复**：原子写语义由 `.tmp` + rename 实现与取消用例保证；e2e 强杀会破坏 Playwright 会话，未纳入。
- **加密图片**：位图无密码解密语义，归入解码失败分支；未额外采集加密容器样本。
