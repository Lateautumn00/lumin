## 2. R2 八类异常（逐条真实记录）

| #   | 场景          | 操作                                                                                                                                | 实测结果                                                                                                                                                                                                         |
| --- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 中文/空格路径 | e2e 用例 2：临时目录（ASCII，规避本机 Node fs 非 ASCII 目录硬崩）内造 `照片 一.txt`、`照片 二.txt`，经 bridge `scan` → `apply` 改名 | progress → done；2/2 改名成功，磁盘实际为 `001-照片 一.txt`/`002-照片 二.txt`；中文与空格全链路无损                                                                                                              |
| 2   | 文件被占用    | PowerShell `[IO.File]::Open(...,'ReadWrite','None')` 独占锁 `a.txt`，再执行 `fs.rename`（与 node.ts 同一系统调用）                  | `EBUSY`；工具侧归类 `FR_RENAME_FAILED`（message=errno `EBUSY`），批次内其余条目继续（单测 `node.test.ts`「来源不存在 FR_RENAME_FAILED 不中断」覆盖同路径）                                                       |
| 3   | 加密文件      | `cipher /e secret.txt`（EFS）后改名                                                                                                 | 成功（`EFS-RENAME OK`）。重命名只改目录项元数据，不读取文件内容，加密状态不影响                                                                                                                                  |
| 4   | 超大文件      | `ftruncate` 造 1.0GB 文件后改名                                                                                                     | 成功，耗时 **1ms**（元数据操作，与体积无关）。工具链路上限为「扫描 5000 条截断」，不按体积过滤                                                                                                                   |
| 5   | 任务取消      | e2e 用例 4：300 个文件提交 `apply` 后立即 `lumin:task:cancel`                                                                       | 终态 `done`（任务已完成）或 `CANCELLED`；目录仍为 300 项，每项为原名或 `renamed-*` 新名，**无临时中转文件**                                                                                                      |
| 6   | 并发溢出      | 连续提交 3 个 `apply` 任务（各自独立目标）                                                                                          | 队列串行（`shell.taskConcurrency` 默认 2）全部 `done`，无交叉污染。`QUEUE_FULL`（maxPending=100）属壳 `task-queue` 单测口径；本工具单任务毫秒级，UI 侧按「执行中禁用执行/撤销/勾选」防重入，如实记录无法自然溢出 |
| 7   | 磁盘满        | 重命名不写数据，等效场景 = 目录 ACL 拒绝写/删：`icacls <dir> /deny "%USERNAME%:(WD,AD)"` 后改名                                     | `EPERM` → 工具侧 `FR_RENAME_FAILED`；`icacls /remove:d` 恢复后同一改名 **成功**（`RESTORE OK`），支持「重试」按钮语义                                                                                            |
| 8   | 断电恢复      | e2e 用例 5：1000 文件 `apply` 进行中 `taskkill /PID <main> /F /T` 强杀，重启应用后 `scan` 复核                                      | 1000 项全部存在（原名或 `renamed-*`），**无半成品/中转残留**；逐个 rename 为原子系统调用，无需恢复日志                                                                                                           |

## 3. 三态与交互（R4）

| 状态   | 记录                                                                                                                      |
| ------ | ------------------------------------------------------------------------------------------------------------------------- |
| 空态   | 未选目录显示「选择一个文件夹开始批量重命名」；已选空目录显示「目录内没有可重命名的文件」+ [换个目录]（e2e 用例 1）        |
| 加载态 | 目录读取显示「读取目录中…」；改名任务显示 `TaskProgress`（当前/总数 + 当前文件名 + 取消按钮，e2e 用例 2/4 收到 progress） |
| 报错态 | 结构化错误码 → 中文文案 + [重试] + 可展开「详情」（detail = errno/stderr 摘要）                                           |

其它验证：

- 规则叠加顺序（删除字符 → 查找替换 → 大小写 → 序号 → 日期 → 扩展名）由 `rules.test.ts` 逐条断言；正则非法时预览显示警告且执行按钮禁用。
- 冲突（与未勾选现存文件重名、批内重名、链式/交换）在预览期即标 `FR_CONFLICT`，执行按钮禁用（e2e 用例 3 验证运行期占用兜底：单条失败不中断，其余照常完成）。
- 撤销：会话内单次，按反向 pairs 执行，同样走三段式任务与进度/取消；撤销后再次执行需重新预览确认。
- 扫描上限 5000 条（超出截断并提示）；仅处理当前目录普通文件，不递归、不含子文件夹。

## 4. 已知限制

- 不提供跨会话撤销与操作历史（settings 仅记忆 `lastDir`）。
- 不做临时中转改名：交换/成环在预览期判冲突，避免断电残留。
- 正则替换仅支持 `$1`–`$9` 反向引用，不支持命名分组与 `$&`。
