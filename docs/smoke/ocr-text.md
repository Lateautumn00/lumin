## 3. 不可实测项说明

- **真实文件占用**：Windows 下图片查看器以共享读打开，难以稳定制造 EBUSY；占用映射由单测覆盖同一代码路径。
- **磁盘满**：未建 VHD 定向模拟 ENOSPC；导出写失败分支由单测（注入 `writeAtomic` 抛 `ENOSPC`）覆盖。
- **断电恢复**：原子写语义由 `node-kit.writeAtomic` 单测与实现保证；e2e 强杀会破坏 Playwright 会话，未纳入。
- **取消时点**：批量识别耗时取决于张数；取消链路复用壳通用 `lumin:task:cancel`（已在 shell 冒烟覆盖），本工具单测验证信号透传。

## 6. M64 增量（2026-11-24：PDF 多页输入）

### 6.1 实现摘要

- 白名单：`INPUT_RE = /\.(png|jpe?g|webp|pdf)$/i`，单张/批量 DropZone `accept` 加 `.pdf`。
- 逐页：`ocr-kit.renderOcrInput(inputPath, { maxPages: 30 })` 渲染 + 逐页 `detectLines`；多页非空文本按「===== 第 N 页 =====」分段，空白页不产生空段。
- 上限：单 PDF ≤30 页（`OCR_PDF_TOO_MANY_PAGES`，渲染前判定，不中断整批）；体积仍 20MB。
- 结果：`done` 项增 `pageCount`；详情显示「N 页 · W×H 像素 · X 字」；PDF 列表/详情用文件图标占位，不出现破图。
