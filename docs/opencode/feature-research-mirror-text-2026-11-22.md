# 图片文字镜像复原 — 技术调研报告

> **状态：调研建议稿，未生效。** 任何结论在拍板并回写 `docs/opencode/plan.md` §1 决策总表（R8）前均不构成需求；口头无效。
> 编制：2026-11-22 · 范围：仅调研，不含实现代码。
> 关联基线：`AGENTS.md`、`docs/opencode/plan.md`、`packages/ocr-kit`、`packages/tools/image-toolbox`、`packages/tools/image-watermark`。
> 结论先行：**功能可实现，但必须按场景分层承诺**。全图镜像可做到像素级完美复原；局部镜像可自动检测与还原，但「文字 mask 外像素零改动」是硬约束，「mask 内背景零改动」在数学上不成立；复杂纹理背景、手写体、低分辨率、曲面反射无法承诺 95%。

## 1. 结论摘要

| 维度 | 结论 |
| --- | --- |
| 可实现性 | **可实现**。全图镜像（自拍/前置摄像头/整页扫描）→ 直接整图翻转，零算法风险、零失真；局部镜像（玻璃反射、双面透印、印章、金属雕刻）→ 可自动检测、定位、逐行判向并局部回翻，主要风险在「背景修复」而非「文字识别」 |
| 推荐技术路线 | **复用现有 PP-OCR det/rec + 双通道置信度判向 + 行级聚类 + 像素级回翻/蒙版合成**；不引入端到端反像模型，不训练新模型，不依赖云端 |
| 新增模型 | **0 个**（复用 `packages/ocr-kit` 的 det/rec/dict，约 16.2MB 现有资产） |
| 新增依赖 | **0 个**（像素操作用已有的 `@napi-rs/canvas` 1.1.1；背景修复基线可用已随包的 ffmpeg `removelogo`） |
| 准确率 | 印刷体、字高 ≥20px、倾斜 ≤15°、纯色/简单背景：字符准确率 **≥98%**，可达 95% 目标；手写体 85–92%；低分辨率（<12px）70–85%；曲面/水面倒影不承诺 |
| 耗时（1080P，单图） | 预计 P50 **2.4–3.2s**、P95 **≤4s**（20 行文本，双通道判向），可取消；全图镜像场景 **1.5–2.2s** |
| 非文字保真 | 文字 mask（外扩 2px）**外**：PNG 输出可做到逐像素零差异；mask **内**：文字笔画像素来自「翻转后的原始笔画」，形状/字体完全一致；仅笔画下背景为修复合成，存在可见性风险 |
| 最大风险 | ①「非文字零改动」与「文字重绘」存在定义冲突，须重定义验收口径；②JPEG 重新编码会改变全图像素，保真测试必须用 PNG/无损输出；③复杂纹理背景修复会出现模糊/涂抹 |
| 结论 | **建议立项，按 P0→P2 分期**：P0 全图镜像（高价值、零风险）→ P1 区域级整块回翻（纯色背景）→ P2 墨迹蒙版回翻 + 背景修复（复杂背景） |

## 2. 需求拆解与验收口径重定义

### 2.1 功能定义

输入：单张静态图片（PNG/JPEG/WebP，建议 ≤50MP）。
输出：

1. 复原后的图片（镜像文字区域变为正向可读，非文字元素保持）；
2. 结构化文本（逐行文本、坐标、判向结果、置信度）；
3. 可选的逐行/逐区域人工确认结果。

### 2.2 关键矛盾：「非文字完全不变」的数学边界

镜像文字复原只有两条物理路径：

| 路径 | 做法 | 文字 | 文字下背景 | 非文字区域 |
| --- | --- | --- | --- | --- |
| A. 整块回翻 | 对文字区域做水平翻转 | 完美（原始像素） | 同步被镜像 | 区域外不变；区域内背景被镜像 |
| B. 墨迹回翻 + 背景修复 | 翻转区域，取文字墨迹蒙版贴回原图，原文字位置背景用修复填充 | 完美（原始像素） | 修复合成（非原始） | 区域外不变；文字笔画下背景为合成 |

因此：

- 「非文字元素完全不变」只能定义为 **文字 mask（含 2px 膨胀）之外逐像素不变**；
- 文字笔画覆盖的背景像素，在路径 B 中必然被替换为修复结果，在路径 A 中必然被镜像——二者都无法保留「原始背景 + 正向文字」；
- 若背景是纯色/纸面/渐变，路径 A 的镜像背景在视觉上通常不可察觉，可作为默认；
- 若背景是纹理/照片/强反光，路径 A 会造成明显穿帮，必须用路径 B，并接受笔画下小面积修复痕迹。

> 报告建议：验收口径写为「文字 mask 外零差异；mask 内文字笔画与原始笔画同源（路径 A/B），背景修复区域需通过 SSIM/人工双签」。不写「全图零改动」，否则任何方案都无法通过。

### 2.3 准确率口径

| 指标 | 定义 | 说明 |
| --- | --- | --- |
| 方向判定准确率 | 逐行判为「正常/镜像/不确定」与真值一致的比例 | 「不确定」单列覆盖率，不计入正确 |
| 字符准确率 | `1 - CER`，CER = 编辑距离 / 真值字符数 | 主指标，对应「95%」 |
| 行完全匹配率（LEM） | 整行文本完全正确的行数 / 总行数 | 辅助指标，建议 ≥85% |
| 检测召回率 | 被检出的镜像文字行 / 真值镜像文字行 | 建议 ≥97% |
| 非文字保真 | mask 外像素差异数 = 0（PNG）；mask 内 SSIM | 见 §2.2 |
| 耗时 | 端到端 P50/P95，含解码与编码 | 明确 CPU 型号与线程数 |

### 2.4 输出格式与色彩管理

- **保真测试与交付默认 PNG**；JPEG 重新编码会改变全图 DCT 系数，无法满足「非文字零差异」，若必须输出 JPEG，应改为「质量 ≥95 + 全图 PSNR ≥45dB」口径。
- 保留 ICC 色彩配置与 EXIF 方向；处理前先按 EXIF 转正，输出时写回方向标记或直接烘焙。
- 带 alpha 的 PNG/WebP 需保留 alpha；动图（GIF/APNG/动态 WebP）首版不支持，明确报错。

## 3. 场景分类与难度

### 3.1 按镜像成因

| 成因 | 典型图片 | 几何类型 | 难度 | 首选策略 |
| --- | --- | --- | --- | --- |
| 前置摄像头/自拍 | 手机自拍、直播截图 | 整图水平镜像 | 极低 | 整图回翻（M0） |
| 整页扫描/翻拍 | 试卷、合同、书页 | 整图镜像或 180° | 极低 | 整图回翻 |
| 玻璃/镜面反射 | 橱窗、后视镜、屏幕 | 区域水平镜像 + 透视 | 中 | 区域回翻（M1/M2） |
| 双面印刷透印 | 薄纸、书页背透 | 区域镜像 + 低对比度 | 中高 | 区域回翻 + 对比度增强 |
| 水面倒影 | 湖边招牌、雨地 | 垂直镜像 + 波纹/曲面 | 高 | 首版不承诺 |
| 印章/钢印 | 公章、火漆、金属压印 | 区域镜像 + 凹凸光影 | 高 | 仅识别文本，不改图 |
| 金属/亚克力雕刻 | 铭牌、奖杯 | 区域镜像 + 高光/阴影 | 高 | 仅识别文本或人工确认 |
| 屏幕/镜面自拍 | 手机对镜自拍 | 整图镜像 + 局部遮挡 | 低中 | 整图回翻 |
| 设计稿/艺术字 | 海报、Logo | 任意角度反射 | 中 | 区域回翻，人工框选 |

### 3.2 按镜像几何

| 类型 | 变换 | 处理 |
| --- | --- | --- |
| 水平镜像（左右） | `x' = W - x` | 主力场景，直接水平翻转 |
| 垂直镜像（上下） | `y' = H - y` | 水平翻转 + 180° 旋转组合 |
| 180° 旋转 | `(x,y) → (W-x, H-y)` | 现有方向分类器可覆盖，不属于严格镜像 |
| 任意角度反射 | 关于角度 θ 的直线反射 | 需估计反射轴，仿射矫正 |
| 透视反射 | 单应变换 | 需四角点/灭点估计，首版人工框选 |
| 曲面反射 | 非刚性形变 | 需 TPS/文档矫正模型，首版不支持 |

### 3.3 按文字与背景

| 维度 | 易 | 中 | 难 |
| --- | --- | --- | --- |
| 字体 | 黑体/宋体/无衬线印刷 | 衬线、细体、艺术字 | 手写、连笔、像素字、花体 |
| 语言 | 中/英/日/韩印刷 | 繁中、俄文 | 阿拉伯文（RTL 连写）、泰文、混合排版 |
| 字号 | ≥24px | 12–24px | <12px |
| 对比度 | 高对比黑白 | 低对比/半透明 | 与背景同色、镂空、发光 |
| 背景 | 纯色/纸面 | 渐变/简单纹理 | 照片/复杂纹理/强反光 |
| 完整性 | 完整文字行 | 部分遮挡/截断 | 大面积遮挡、弯曲、模糊 |

## 4. 技术方案对比

### 4.1 传统图像处理

| 方法 | 原理 | 能力 | 局限 | 结论 |
| --- | --- | --- | --- | --- |
| 全局翻转 + OCR 置信度比较 | 原图与水平翻转图各跑一次 OCR，比较识别置信度 | 判断整图是否镜像，准确率高、实现简单 | 只能整图，不能定位局部 | **推荐用于整图判定** |
| Leptonica `pixMirrorDetect` | 统计文字行像素分布/字符上升部对齐，检测整页水平翻转 | 文档整页镜像检测，经典稳定 | 仅整页、需足够文本、不定位 | 可作为整图判定的辅助信号 |
| 投影/对称性分析 | 文字行墨迹投影不对称性 | 辅助判断 | 对居中/对称排版失效 | 不单独使用 |
| 模板匹配 | 匹配已知字体/标志（如车头 `AMBULANCE`） | 特定场景 | 泛化差 | 仅作补充 |
| 边缘/角点 + 反射轴估计 | Hough/消失点估计镜面 | 透视矫正 | 复杂背景不稳 | P3 研究 |

### 4.2 OCR + 方向校正（工业主流）

现有能力盘点：

| 能力 | 现状 | 是否覆盖镜像 |
| --- | --- | --- |
| PP-OCR 文本检测（DBNet） | 检测文字行，输出四点框 | 检测本身通常不区分正反/镜像 |
| PP-OCR 文本行方向分类 | **仅 0°/180° 两类**（`PP-LCNet_x0_25_textline_ori` Top-1 98.85%，0.96MB，CPU 2.37ms） | **否** |
| PP-OCR 文档方向分类 | 0°/90°/180°/270° 四类 | **否** |
| PP-OCRv5 预处理 | 方向分类 + 文本图像矫正（unwarping） | **否**（矫正几何形变，不处理镜像） |
| 云 OCR（腾讯等） | 支持 90/180/270 翻转与倾斜 | 公开文档未见镜像专项 |

> 结论：**现成 OCR 没有「镜像」这个类别**，必须自行构造判定信号。

可行的判定信号（按优先级）：

1. **双通道识别置信度差**：同一行裁剪分别按原图与水平翻转送入 rec，比较长度归一化的 CTC 平均置信度。镜像文本在原图通道通常输出乱码/低置信，翻转通道显著更高。
2. **语言模型/词典校验**：对两通道文本做字符/词频打分（中文可用常用字表，英文可用词典），与置信度融合。
3. **检测回退**：若原图检测不到文字，对水平翻转图再检测一次，将框坐标映射回原图。
4. **轻量二分类器（可选）**：合成「正常/镜像」文本行训练 1–2MB 分类器；首版不必需。

优点：零新模型、多语言、可解释、可逐行给出「不确定」。
缺点：rec 成本 ×2；极低分辨率下两通道都低置信；需按语言校准阈值。

### 4.3 端到端反像文字检测/识别（学术前沿）

| 工作 | 要点 | 工程可用性 |
| --- | --- | --- |
| IATS（IEEE TIP 2024） | 统一端到端框架，阅读顺序估计 + 动态采样，专门处理 mirrored/symmetrical/retro-flexed | 研究代码，无成熟 ONNX/Electron 集成，训练成本高 |
| InverseText 数据集 | 500 张测试图，约 40% inverse-like 实例，部分因拍摄产生镜像 | 可作评测集，规模小 |
| SSM（2024） | 对称叠加自监督预训练，让 STR 重建方向相关像素/特征 | 预训练方法，不直接提供产品级检测 |
| 通用 STR 模型 | 对翻转输入敏感，标准训练不含镜像增广 | 不能直接读镜像 |

评价：这些工作证明「反像文字」是独立研究问题，但**不适合作为 Lumin 首版依赖**：模型体积、推理框架、训练数据、维护成本都不可控，且只解决识别、不解决「非文字保真」。

### 4.4 文本擦除与背景修复

| 方法 | 类型 | 质量 | 体积/速度 | 适用 |
| --- | --- | --- | --- | --- |
| OpenCV Telea / Navier-Stokes | 传统修复 | 小区域尚可，纹理模糊 | 快（毫秒级） | 细笔画、纯色/渐变背景 |
| ffmpeg `removelogo` / `delogo` | 传统插值 | 中等，边缘可能糊 | 快，已随包 | 低成本基线，整图一次 mask 处理 |
| EraseNet | GAN 两阶段 | 好 | GPU 模型，体积大 | 复杂背景，离线重 |
| CTRNet / CTRNet++ | 局部-全局上下文 | 好 | 重 | 同上 |
| FETNet / DeepEraser | 特征擦除/迭代上下文 | 好 | 重 | 同上 |
| DiffSTR | 扩散模型 | 很好 | 约 2 FPS（GPU） | 质量优先，不适合桌面 CPU |
| LaMa | 大感受野修复 | 很好 | 45.6M 参数，174MB（FP32），512×512 | 可选高质量模式，CPU 慢 |
| EnsNet | 轻量 GAN | 中 | 论文称 i5-8600 CPU 333 FPS（小分辨率） | 可评估 ONNX 化 |

评价：**首版不引入生成式修复**。文本笔画很细，修复区域是「笔画形状」而非整块矩形，传统修复在小区域上性价比最高；复杂纹理背景的可见痕迹应通过「整块回翻」或人工确认规避，而不是堆大模型。

### 4.5 文字重渲染（OCR → 字体重绘）

| 环节 | 难点 |
| --- | --- |
| 字体识别 | 需字体识别模型/字库比对，中文艺术字极难 |
| 字号/字距/基线 | 可从行高与投影估计，但不等宽字体误差大 |
| 颜色/描边/阴影 | 需逐像素估计，半透明/渐变几乎不可还原 |
| 字库授权 | 商用字库不能随包分发；开源中文字体（如 Noto Sans SC）与原文风格不一致 |

结论：重渲染**无法满足「视觉一致」**，只适合「输出可编辑文本/重新排版」的增值场景（M3），不作为默认复原路径。相比之下，§5 的「像素级回翻」能保留原始字形，是本方案的核心优势。

### 4.6 综合对比

| 方案 | 定位 | 判向 | 复原保真 | 多语言 | 新依赖 | 速度 | 成熟度 | 建议 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 整图翻转 + OCR 校验 | 全图镜像 | 强 | 完美（整图即真值） | 强 | 无 | 快 | 高 | **P0 必做** |
| 传统图像处理定位 | 局部镜像 | 弱 | 不适用 | — | 无 | 快 | 中 | 仅辅助 |
| OCR + 双通道判向 | 局部镜像 | 强 | 取决于合成 | 强 | 无 | 中 | 高 | **P1/P2 核心** |
| 端到端反像模型（IATS） | 局部镜像 | 很强 | 仅文本 | 中 | 大 | 慢 | 低 | 观察，不落地 |
| 文本擦除 + 重渲染 | 局部镜像 | 依赖 OCR | 差（字体不一致） | 中 | 大 | 慢 | 中 | 仅 M3 增值 |
| 像素回翻 + 蒙版合成 | 局部镜像 | 依赖 OCR | **字形完美，背景修复** | 强 | 无 | 快 | 中 | **推荐核心** |

## 5. 推荐技术路线

### 5.1 总体流程

```
解码/EXIF 转正
  → 全图镜像判定（双通道 OCR 置信度）
      ├─ 是 → 整图水平翻转 → 重新 OCR → 输出（M0）
      └─ 否 → 行检测（det，长边 960）
              → 逐行双通道判向（原图 vs 翻转，rec 置信度差）
              → 行级标签聚类成区域（同向 + 邻接）
              → 逐区域选择复原模式（M1/M2/M3）
              → 像素回翻 / 蒙版合成 / 背景修复
              → 再 OCR 校验 + 输出图片与文本
```

### 5.2 全图镜像判定（P0）

- 原图与水平翻转图各跑一次完整 OCR（或仅对检测到的行做 rec）。
- 打分：`score = 平均行置信度 × 文本有效率`；`Δ = score_flip - score_orig`。
- `Δ > θ_global`（建议 0.15，需标定）→ 判定整图镜像，直接翻转整图。
- 该路径**没有背景修复问题**：整图翻转就是真实场景的正确还原，非文字元素也回到正确位置。
- 适用：自拍、前置摄像头、整页扫描、对镜自拍。

### 5.3 行级检测与双通道判向（P1）

1. det 在原图检测行框；若行数明显偏少，对翻转图再检测并按 `x' = W - x` 映射回原图，合并去重。
2. 每行裁剪（含 10% 外扩），分别送入 rec：
   - 原图通道：`text_o, conf_o`
   - 翻转通道：`text_f, conf_f`
3. 置信度定义为 CTC 非 blank 位置的平均概率（长度归一化），避免长行/短行偏置。
4. 判定：
   - `conf_f - conf_o > θ_line` → 镜像；
   - `conf_o - conf_f > θ_line` → 正常；
   - 否则 → 不确定，交给用户确认（不自动改图）。
5. 文本选择：取置信度高且通过语言校验的一侧；两侧都低 → 仅标记区域，不改图。

> 工程改造点：`packages/ocr-kit` 当前 `OcrLine` 只有 `text/x/y/width/height`，`decodeBatch` 不返回置信度。需要**新增行级 score 输出**（向后兼容，默认字段可选），并补单测；该改动会影响 exam-split / ocr-text 等调用方，须全仓回归。

### 5.4 区域聚合

- 输入：带 `{normal | mirrored | uncertain}` 标签的行框。
- 聚合规则：同标签 + 行间距 < 2×行高 + 水平重叠或阅读顺序连续 → 合并为一个区域。
- 区域几何：取行框并集的凸包/外接矩形；对透视场景可退化为四边形（P3）。
- 输出：区域列表（bbox、标签、行列表、平均置信度、建议模式）。

### 5.5 复原模式

| 模式 | 做法 | 非文字保真 | 文字保真 | 适用 | 风险 |
| --- | --- | --- | --- | --- | --- |
| **M0 仅文本** | 不改图，只输出正向文本 | 100% | 不适用 | 复制、检索、核对 | 无 |
| **M1 整块回翻** | 对区域做水平翻转，覆盖原区域 | 区域外 100%；区域内背景被镜像 | 完美（原始像素） | 纯色/纸面/渐变/对称背景；全图镜像 | 纹理背景穿帮 |
| **M2 墨迹蒙版回翻** | 翻转区域 → 提取文字墨迹 alpha → 原图文字位置背景修复 → 合成 | 区域外 100%；笔画下为修复 | 完美（原始笔画像素） | 复杂背景、玻璃反射、透印 | 修复痕迹、alpha 估计误差、光晕 |
| **M3 重绘** | OCR 文本 + 字体/颜色/字号估计后重排 | 区域外 100%；区域内全部重绘 | 差（字体不一致） | 需要可编辑/放大/翻译 | 视觉不一致，字库授权 |

默认策略：

- 全图镜像 → M1（整图）；
- 区域背景方差低于阈值（纯色/纸面）→ M1；
- 背景方差高或含纹理 → M2；
- 用户选择「只提取文字」→ M0；
- M3 仅作为后续增值，不进入首版验收。

### 5.6 M2 像素合成细节

1. **翻转**：对区域裁剪图做水平翻转，得到 `flipCrop`。
2. **墨迹 alpha 估计**：
   - 估计局部背景色（行列分位数/中值滤波）；
   - 在 Lab 空间计算每个像素与背景的距离，归一化为 alpha；
   - 对 alpha 做 1px 羽化，避免硬边。
3. **背景修复**：
   - 用原图文字 mask（alpha > 阈值，外扩 2px）生成修复 mask；
   - 基线：ffmpeg `removelogo`（整图一次处理，零新依赖）；
   - 备选：自研 Telea/扩散修复（小区域，纯 TS，便于单测）；
   - 高质量可选：LaMa ONNX（174MB，默认不随包）。
4. **合成**：`out = repairedBackground × (1 - alpha) + flipCrop × alpha`。
5. **边界检查**：mask 外逐像素断言不变；mask 边缘梯度差超过阈值 → 提示人工确认。

> 关键点：M2 的文字像素来自「翻转后的原始笔画」，因此字体、字重、抗锯齿、颜色都与原文同源；与「OCR 后重绘」相比，视觉一致性有数量级提升。

### 5.7 交互与质量控制

- 自动结果以「行级徽标」呈现：绿色=正常、橙色=镜像已复原、灰色=不确定。
- 不确定行必须人工点选「翻转/保持/忽略」，不允许静默改图。
- 提供 before/after 滑块对比与「仅看差异」视图。
- 三态：空态（拖拽/选择图片 + 说明）、加载态（进度 + 取消）、错误态（结构化错误码 + 重试）。

## 7. 性能预算（1080P，单图）

### 7.1 分解（20 行文本，双通道判向）

| 阶段 | 预计耗时 | 依据 |
| --- | --- | --- |
| 解码 + EXIF 转正（PNG 1080P） | 30–60ms | `@napi-rs/canvas` |
| det（长边 960，CPU） | 550–700ms | 现有 exam-split 实测 609ms/页 |
| rec 原图通道（20 行，前缀裁剪） | 约 0.7–0.8s | 现有实测 38ms/行 |
| rec 翻转通道（20 行） | 约 0.7–0.8s | 同上 |
| 判向 + 聚类 | <50ms | 纯计算 |
| mask + 背景修复（M2，小区域） | 100–300ms | ffmpeg `removelogo` 单次整图；自研修复视面积 |
| 编码 PNG | 100–200ms | 1080P |
| **合计** | **P50 2.4–3.2s · P95 ≤4s** | 需实测 |

优化项：

- 全图镜像场景只需「一次 det + 两次 rec（原图/翻转）」，约 1.5–2.2s。
- 若升级到 PP-OCRv5 mobile rec（16MB，CPU 21.2ms），rec 合计可降至约 0.9s，总耗时约 1.8–2.5s。
- 4K 图：det 仍缩到 960，rec 用原始裁剪，预计 3–5s；超大图建议分块或先缩放到 1080P 预览再全分辨率输出。
- 批量：串行或并发 2；单任务内存预计 300–500MB；取消用 AbortSignal 杀树，已完成文件保留。

### 7.2 「可接受」的定义建议

- 1080P 单图 P95 ≤4s，取消响应 ≤500ms；
- 不阻塞主进程（worker 内执行）；
- 进度条按「解码 → 检测 → 识别 → 合成 → 编码」五段上报。

## 8. Lumin 落地方案

### 8.1 包与目录（遵守 AGENTS §2/§3）

```
packages/tools/mirror-text/
  src/
    manifest.ts          # toolId: mirror-text，分组 image，懒加载
    schema.ts            # IPC zod schema（analyze/process/cancel/config）
    errors.ts            # 结构化错误码
    node.ts              # 主进程：注册通道，spawn worker
    mirror.worker.ts     # 解码 → OCR → 判向 → 聚类 → 合成 → 编码
    orient.ts            # 纯函数：双通道判向、聚类（≥80% 单测）
    composite.ts         # 纯函数：翻转/mask/alpha/合成（≥80% 单测）
    renderer/
      ToolView.vue       # 三态 + 画布 + 行级徽标 + before/after
      client.ts          # 类型化 IPC client
      canvas.ts          # 预览绘制（不 import main）
```

依赖方向：`mirror-text` → `plugin-api / shared / ui / node-kit / ocr-kit`；禁止 import `apps/*` 或其他工具。
像素库：直接用 `@napi-rs/canvas`（1.1.1，已在 node-kit/ocr-kit/image-watermark 使用），不新建公共包；若后续第二个工具复用合成逻辑，再上提。

### 8.2 IPC 契约（三段式）

| 通道 | 类型 | 入参 | 回包 |
| --- | --- | --- | --- |
| `mirror-text:analyze` | task | `{ path }` | `{ taskId }` → 事件：`progress` / `done { regions, lines, globalMirror }` / `error` |
| `mirror-text:process` | task | `{ path, mode, regions, outputDir, format }` | `{ taskId }` → `progress` / `done { outputPath, text }` / `error` |
| `mirror-text:cancel` | sync | `{ taskId }` | `{ ok }` |
| `mirror-text:config` | sync | — | `{ outputDir }` / 设置 |

- 所有入参 zod 校验；路径白名单；错误码统一 `MIRROR_*`（如 `MIRROR_DECODE_FAILED`、`MIRROR_NO_TEXT`、`MIRROR_OCR_FAILED`、`MIRROR_CANCELLED`、`MIRROR_WRITE_FAILED`）。
- 任务并发上限沿用壳队列；OCR worker 内串行。

### 8.3 UI 三态

| 状态 | 内容 |
| --- | --- |
| 空态 | 拖拽区 + 支持格式说明 + 「选择图片」按钮；示例图入口（可选） |
| 加载态 | 五段进度 + 当前阶段文案 + 取消按钮 + 已耗时 |
| 报错态 | 错误码 → 中文文案 + 重试 + 打开日志目录 + 详情折叠 |

结果区：图片画布 + 行级徽标 + 区域列表 + 模式切换（仅文本/整块回翻/蒙版回翻）+ 导出 PNG/JPEG + 复制文本。

### 8.4 依赖与体积成本

| 项 | 体积 | 是否新增 | 说明 |
| --- | --- | --- | --- |
| PP-OCR det/rec/dict | 16.2MB | 否 | `binaries/ocr`，已有 SHA256 校验 |

- 安全：主进程安全基线不下调；不联网；文件写入限制在用户选择目录。

## 9. 实施步骤（分期）

### P0：全图镜像复原（最小可用）

交付：

- 新工具包 `mirror-text` + 清单注册；
- 解码/EXIF 转正；
- 全图双通道 OCR 判定；

- 三态 UI、进度、取消；
- 单测（判向/坐标/编码）+ IPC 冒烟 + smoke 文档。

退出标准：自拍/扫描测试集判向 ≥99%，整图回翻输出与真值逐像素一致（PNG），P95 ≤3s。

### P1：区域级检测与整块回翻（M1）

交付：

- 行检测 + 行级双通道判向 + 不确定标记；
- 区域聚类 + 画布徽标 + 人工框选/调整；
- M1 整块回翻（纯色/渐变背景）；
- 区域级 before/after 对比。

退出标准：印刷体纯色背景字符准确率 ≥98%，方向判定 ≥99%，mask 外零差异（PNG）。

### P2：墨迹蒙版回翻 + 背景修复（M2）

交付：

- alpha 估计 + mask 膨胀/羽化；
- 背景修复（ffmpeg `removelogo` 基线，或自研 Telea）；
- 合成质量提示与人工确认；
- 批量处理（可选）。

退出标准：纹理背景字符准确率 ≥95%，mask 外零差异，mask 内 SSIM ≥0.90（纯色）/人工双签（纹理），P95 ≤4s。

### P3：增强能力（可选/研究）

- 透视/反射轴估计，支持倾斜玻璃；
- 高质量修复（LaMa ONNX 按需下载）；
- M3 OCR 重绘/翻译/放大；
- 阿拉伯文等 RTL 语言评估；

## 10. 测试与验证标准

### 10.1 测试集

| 类别 | 数量建议 | 构造方式 | 用途 |
| --- | --- | --- | --- |
| 合成镜像集 | 500 | 取干净文档/UI/招牌截图，水平翻转得到输入，原图为真值 | 像素保真、字符准确率 |
| 合成局部镜像集 | 300 | 在正常图上选区翻转并拼接，记录 mask 真值 | 区域检测、mask 外零差异 |
| 真实镜像集 | 100 | 自拍、玻璃反射、透印、印章、雕刻、低分辨率 | 泛化与边界 |
| 异常集 | 每类 ≥3 | 中文/空格路径、占用、加密、超大、取消、并发、磁盘满、断电 | smoke |

标注字段：图片、区域四边形、行框、真值文本、镜像类型、语言、字体、字高、背景类型、难度等级。

### 10.2 指标计算

```
方向判定准确率 = 正确标签行数 / 总行数          （uncertain 不计正确）
字符准确率     = 1 - editDistance(pred, gt) / len(gt)
行完全匹配率   = 完全正确行数 / 总行数
mask 外差异    = count(pixel_out != pixel_gt_out)   // 必须为 0（PNG）
mask 内 SSIM   = SSIM(out_mask, gt_mask)
P95 耗时       = 第 95 百分位端到端耗时
```

### 10.3 验收阈值（建议）

| 项 | 阈值 | 备注 |
| --- | --- | --- |
| 全图镜像判向 | ≥99.5% | P0 |
| 局部行判向（印刷体） | ≥99% | P1 |
| 字符准确率（印刷体/纯色/≥24px） | ≥98% | 覆盖 95% 目标 |
| 字符准确率（纹理背景） | ≥95% | P2 |
| 行完全匹配率（印刷体） | ≥85% | 辅助 |
| 检测召回率 | ≥97% | — |
| mask 外像素差异 | = 0（PNG） | 硬门禁 |
| mask 内 SSIM（纯色背景） | ≥0.95 | P2 |
| P95 耗时（1080P） | ≤4s | 参考 CPU 明确 |
| 取消响应 | ≤500ms | — |
| 单任务内存 | ≤800MB | — |

### 10.4 八类异常（AGENTS §7.3）

1. 中文/空格路径：读写正常，日志不截断；
2. 文件被占用：结构化错误 + 重试提示；
3. 加密/损坏图片：解码失败错误码；
4. 超大图片：尺寸/内存上限，明确提示；
5. 任务取消：≤500ms 停止，临时文件清理；
6. 并发溢出：队列排队或明确拒绝；
7. 磁盘满：写入失败错误码，不产生半成品；
8. 断电恢复：临时文件原子写（写 `.tmp` 再 rename），重启可清理。

### 10.5 自动化门禁

- 单测：`orient.ts` / `composite.ts` 覆盖率 ≥80%；
- 集成：IPC `analyze → done` 冒烟 1 条；`process → cancel` 1 条；
- 像素断言：合成镜像集固定 20 张做 golden test，mask 外差异必须为 0；
- 性能：CI 跑 1080P 基准，记录 P50/P95（允许机器差异，设宽松上限）；
- 文档：`docs/smoke/mirror-text.md` 全量记录，漏测返工。

## 12. 结论与建议

1. **可实现性：明确可实现，但要分层承诺。**
   - 全图镜像：零风险、像素级完美，建议作为 P0 首发；
   - 局部镜像：可自动检测与还原，印刷体 + 简单背景可达 95%+；
   - 复杂纹理、手写、低分辨率、曲面反射：不承诺 95%，以「识别文本 + 人工确认」降级。
2. **技术选型：复用现有 PP-OCR，不引入新模型/新框架。**
   - 判向用「双通道 CTC 置信度差」，比训练镜像分类器更稳、更省；
   - 复原用「像素级回翻」，保留原始字形，优于 OCR 重绘；
   - 背景修复先用 ffmpeg `removelogo` 基线，质量不足再评估自研 Telea/LaMa。
3. **最大工程风险不在算法，而在验收口径与背景修复。** 建议先与需求方确认 §2.2 的 mask 边界定义，再进入 P1。
4. **建议决策：** 批准 P0+P1 立项；P2 在 P1 验收后按纹理背景实测结果决定；P3 仅预研，不排期。

## 附录 B：术语

| 术语 | 含义 |
| --- | --- |
| 镜像文字 | 经一次反射变换后左右/上下颠倒的文字，字形与阅读顺序同时反转 |
| 反像文字（inverse-like text） | 论文用语，涵盖 mirrored / symmetrical / retro-flexed 等非常规阅读方向 |
| 双通道判向 | 同一文本行分别按原图与水平翻转送入识别器，比较置信度决定方向 |
| M0/M1/M2/M3 | 仅文本 / 整块回翻 / 墨迹蒙版回翻 / OCR 重绘 四种复原模式 |
| mask 外零差异 | 文字蒙版（含 2px 膨胀）之外的像素与输入完全一致 |
| CTC 置信度 | 识别器每帧非 blank 字符概率的均值（长度归一化） |
