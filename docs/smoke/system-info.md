# system-info 冒烟记录（M53）

> 工具：系统信息查看器（`@lumin/tool-system-info`）
> 形态：只读单页；不写文件、不改设置、不联网；单同步通道 `system-info:snapshot`
> 环境：Windows 11 x64（Windows_NT 10.0.22631），记录日期 2026-11-22

## 1. R2 八类异常映射

| # | 场景 | 适用性 | 记录 |
| --- | --- | --- | --- |
| 1 | 中文/空格路径 | N/A | 无路径输入；仅探测固定盘符 `A:`–`Z:`，不接收用户路径 |
| 2 | 文件被占用 | N/A | 不打开文件句柄，仅 `statfs` 读取卷容量，文件锁不影响 |
| 3 | 加密文件 | N/A | 不读取任何文件内容 |
| 4 | 超大文件 | N/A | 不扫描文件，仅聚合 `os` 概览与卷容量 |
| 5 | 任务取消 | N/A | 单次同步采集（毫秒级），不产生可取消长任务；采集期间按钮 `loading` 防重入 |
| 6 | 并发溢出 | 已覆盖 | 采集按钮 `:loading` + `if (loading) return` 防重入；26 个盘符 `Promise.all` 单次探测，失败盘符静默跳过；网卡/磁盘结果分限 32/16 |
| 7 | 磁盘满 | N/A | 零写入，不产生输出文件 |
| 8 | 断电恢复 | N/A | 无落盘状态；重启后回到空态，点击采集即可重建快照 |

## 2. 正向与边界验证

| 场景 | 结果 |
| --- | --- |
| 首次进入 | 空态显示引导「点击『采集系统信息』查看本机 CPU、内存、磁盘与网络概览」+ 主按钮 |
| 点击采集 | 五区（操作系统/处理器/内存/磁盘/网络）与采集时间可见；盘符、网卡、CPU 型号与主频均来自真实系统 |
| 刷新 | 主按钮切换为「刷新」，点击后重新采集并更新时间 |
| 复制全部 | 剪贴板文本包含「操作系统」「处理器」「内存」「磁盘」「网络」「采集时间」五段 |
| 无外部网卡 | 「未检测到外部网络接口」占位（单测覆盖空列表分支） |
| 无可用磁盘 | 「未检测到可访问磁盘」占位（单测覆盖 `statfs` 抛错/容量非法跳过） |
| 采集异常 | 普通异常包装 `SI_COLLECT_FAILED`（中文文案 + 重试 + 详情）；结构化错误原样透传（`node.test.ts` 覆盖） |
| 复制异常 | `SI_CLIPBOARD_FAILED` 中文文案（renderer 捕获剪贴板不可用） |
