# 单位换算 — 字段级功能清单（M1 验收附件）

> 依据 AGENTS §11：开工前定稿。变更须同步更新本文件与 `docs/opencode/plan.md` §4.2。

## 1. 输入项

| 字段 | 类型 | 约束 | 默认值 |
| --- | --- | --- | --- |
| 类别 | `CategoryId` | 10 类之一，见 §2 换算表 | `'length'` |
| 源单位 `fromId` | string | 必须属于当前类别 | 该类别 `units[0]` |
| 目标单位 `toId` | string | 必须属于当前类别；允许与 from 相同 | 该类别 `units[1]` |
| 数值 `value` | string 输入 → number 求值 | 允许负数与小数；`trim()===''` 走空态；非有限数走报错态 | `''` |
| 收藏 | `Record<CategoryId, string[]>` | 单位 id 列表，按类别分组，localStorage 持久化 | `{}` |

## 2. 换算表（10 类，无汇率；数据驱动 `{id, name, factor}`，温度为偏移模型）

线性模型：`base = value × factor`（factor = 相对基准单位的倍数）。
温度模型：`K = value × scale + offset`（`°F: scale=5/9, offset=255.37222…`；`°C: 1/273.15`；`K: 1/0`）。

| 类别 id | 名称 | 基准 | 单位 `{id, 名称, factor/scale+offset}` |
| --- | --- | --- | --- |
| `length` | 长度 | m | m 米(1) · km 千米(1000) · cm 厘米(0.01) · mm 毫米(0.001) · in 英寸(0.0254) · ft 英尺(0.3048) · yd 码(0.9144) · mi 英里(1609.344) |
| `weight` | 重量 | kg | kg 千克(1) · g 克(0.001) · mg 毫克(1e-6) · t 吨(1000) · lb 磅(0.45359237) · oz 盎司(0.028349523125) |
| `temperature` | 温度 | K | K 开尔文(scale 1, offset 0) · C 摄氏度(1, 273.15) · F 华氏度(5/9, 255.37222222222223) |
| `area` | 面积 | m² | m2 平方米(1) · km2 平方千米(1e6) · cm2 平方厘米(1e-4) · mm2 平方毫米(1e-6) · ha 公顷(10000) · acre 英亩(4046.8564224) · ft2 平方英尺(0.09290304) |
| `volume` | 体积 | L | L 升(1) · ml 毫升(0.001) · m3 立方米(1000) · floz 美制液体盎司(0.0295735295625) · pt 美制品脱(0.473176473) · qt 美制夸脱(0.946352946) · gal 美制加仑(3.785411784) |
| `speed` | 速度 | m/s | mps 米/秒(1) · kmh 千米/时(1/3.6) · mph 英里/时(0.44704) · kn 节(1852/3600) · fps 英尺/秒(0.3048) |
| `time` | 时间 | s | s 秒(1) · ms 毫秒(0.001) · min 分钟(60) · h 小时(3600) · d 天(86400) · wk 周(604800) |
| `data` | 数据量 | B | B 字节(1) · bit 比特(0.125) · KB 千字节(1024) · MB 兆字节(1048576) · GB 吉字节(1073741824) · TB 太字节(1099511627776)（**1024 进制**） |
| `pressure` | 压强 | Pa | Pa 帕(1) · kPa 千帕(1000) · bar 巴(100000) · MPa 兆帕(1e6) · atm 标准大气压(101325) · psi 磅力/平方英寸(6894.757293168361) |
| `power` | 功率 | W | mW 毫瓦(0.001) · W 瓦(1) · kW 千瓦(1000) · MW 兆瓦(1e6) · hp 英制马力(745.6998715822702) · PS 公制马力(735.49875) |

- 单位顺序 = 表中顺序（`units[0]` 为默认源单位，`units[1]` 为目标单位）。
- 类别顺序 = 表中顺序；id 唯一、类别内单位 id 唯一、名称唯一、factor>0。

## 3. 操作与错误分支

### 3.1 操作

| 操作 | 行为 |
| --- | --- |
| 切换类别 | from/to 重置为新类别的 units[0]/units[1]；数值保留 |
| 修改数值 | 实时换算（纯同步，无提交按钮） |
| 互换 ⇄ | 交换 from/to；数值不变，结果重算 |
| 收藏星标 | 按当前单位与所在类别 toggle；**收藏单位在两侧下拉列表置顶**（当前类别） |

### 3.2 求值与错误分支

纯函数 `convert(categoryId, fromId, toId, value)` → number；永不静默返回 NaN。

| 分支 | 条件 | 错误码 | 中文文案（呈现） |
| --- | --- | --- | --- |
| 空输入 | `trim()===''` | （空态） | 结果区显示 `—`，不报错 |
| 非法数值 | `Number()` 非有限数 | `INVALID_VALUE` | 请输入有效数值 |
| 未知类别 | 类别 id 不在表中 | `UNKNOWN_CATEGORY` | 不支持的换算类别 |
| 未知单位 | 单位 id 不属于该类别 | `UNKNOWN_UNIT` | 该单位不支持此换算 |

## 4. 三态（R4）

| 状态 | 呈现 |
| --- | --- |
| 空态 | 数值输入 placeholder「输入数值」，结果区 `—`；收藏空态「暂无收藏单位」 |
| 加载态 | N/A（纯同步换算，无长任务）——本工具声明豁免 |
| 报错态 | 输入框下方行内红字（`INVALID_VALUE`），修正输入即恢复 |

## 5. 验收

- **换算表全量断言覆盖 ≥80%**（plan.md §4.2）：每类每单位 × 基准值/往返换算断言；温度锚点（0℃=32℉=273.15K、100℃=212℉、-40℃=-40℉、0K=-273.15℃）
- 数据完整性：10 类齐全、类别内 id/名称唯一、factor>0、`units[0]` 为基准单位
- 收藏置顶与持久化；类别切换重置单位；⇄ 互换结果正确
- 门禁全绿；懒加载 chunk < 200KB（R5，无三方求值库依赖）
