# 文件哈希校验（file-hasher）字段级功能清单

> 版本：v0.1.0 · 定稿日期：2026-11-19（R8）· 工具 id：`file-hasher`
> 本文件为该里程碑验收附件；实现与本文件不一致时以本文件为准，变更须走 R8 流程。

## 1. 范围与边界

**做**：批量选择文件计算 MD5 / SHA-1 / SHA-256（可多选，一次读流同时计算），结果表展示、复制单行/全部、粘贴期望哈希自动比对、失败项重试。

**不做**：目录递归/拖入文件夹展开、导出文件（无保存对话框能力，复制代替）、SHA-512 与其它算法、文件内容修改、i18n（工具页中文直写）。

## 2. 页面字段清单

| 区域   | 控件                                               | 行为                                                              | 空/默认                      |
| ------ | -------------------------------------------------- | ----------------------------------------------------------------- | ---------------------------- |
| 输入区 | 拖拽区 + [选择文件]（隐藏 input）                  | `@lumin/ui` DropZone 多选；`getPathForFile` 取绝对路径            | 空态文案 + 拖拽引导          |
| 输入区 | 已选列表                                           | 文件名 + 大小 + 移除；超 200 个/单文件 >20GB 忽略并中文提示       | 0 项时隐藏                   |
| 输入区 | [清空]                                             | 清空已选、结果与提示                                              | 执行中禁用                   |
| 算法   | MD5 / SHA-1 / SHA-256 复选框                       | 默认仅 SHA-256；至少 1 个，全不选 → [开始校验] 禁用 + 提示        | 读取 `config`（上次勾选）    |
| 操作   | [开始校验]                                         | 提交 `hash` 任务；同时 `set-config` 记忆算法                      | 未选文件/无算法/执行中禁用   |
| 操作   | [取消]                                             | 执行中显示，`lumin:task:cancel`                                   | 仅执行中可见                 |
| 进度   | 阶段（准备/计算） + 已处理/总字节 + 当前文件名     | `prepare` 按文件数、`hash` 按字节（64KB 粒度）                    | 执行中显示                   |
| 结果表 | 文件名（完整路径副行 + tooltip）/大小/修改时间/算法列/状态/[复制本行] | 算法列按勾选顺序展示，等宽字体；失败行显示错误文案                | 无结果时隐藏                 |
| 结果区 | 摘要 + [复制全部]                                  | 「共 N 个文件 · 成功 X · 失败 Y · 耗时 Zs」；TSV 含表头           | 无结果时隐藏                 |
| 结果区 | [重试失败项（N）]                                  | 只重算失败路径，复用当前算法                                      | 无失败项时隐藏               |
| 比对区 | 期望哈希输入框                                     | 支持 `md5:`/`sha1:`/`sha256:`（含 `sha-1:`/`sha-256:`）前缀或无前缀（按 32/40/64 长度识别）；大小写不敏感、去空白、去 `0x` | 空；格式非法红字提示 |
| 比对区 | 命中摘要 + 行高亮                                  | 「按 X 比对，命中 N 个文件」；命中行浅底 + 「匹配」标签           | 未输入/非法时不高亮          |

## 3. 算法与哈希语义

| 算法      | 长度 | 说明                                     |
| --------- | ---- | ---------------------------------------- |
| `md5`     | 32   | 兼容旧校验和                             |
| `sha1`    | 40   | 兼容旧校验和                             |
| `sha256`  | 64   | **默认**，新场景推荐                     |

- 单文件多算法：**一次读流**同时喂多个 `createHash`，避免多遍读盘。
- 逐文件**顺序**处理（I/O 顺序 + 进度稳定），不做跨文件并发。
- 空文件合法：返回空串摘要（如 SHA-256 `e3b0c442…`），不记失败。
- 结果顺序 = 入参 `paths` 顺序。

## 4. 入参校验与边界

| 项             | 约束                                                    | 违反时                            |
| -------------- | ------------------------------------------------------- | --------------------------------- |
| `paths`        | 1–200 个，非空字符串                                    | `FH_INVALID_PAYLOAD`（zod）       |
| `algorithms`   | 1–3 个，枚举 `md5`/`sha1`/`sha256`                      | `FH_INVALID_PAYLOAD`（zod）       |
| 单文件体积     | ≤ 20 GB（统计 `stat.size`，超大不读取）                 | 该行 `FH_FILE_INVALID`「文件超过 20 GB 上限」 |
| 路径类型       | 仅普通文件；目录/不存在/无权限                          | 该行 `FH_FILE_INVALID` + errno 细节 |
| 任务超时       | 30 分钟（`HASH_TIMEOUT_MS`）                            | `FH_HASH_FAILED`「计算超时」      |

## 5. IPC 通道

| 通道                  | 类型 | 入参                                | 出参                                                                                       |
| --------------------- | ---- | ----------------------------------- | ------------------------------------------------------------------------------------------ |
| `file-hasher:hash`    | task | `{paths:string[1..200], algorithms:Algorithm[1..3]}` | `{taskId}`；progress `{stage:'prepare'\|'hash', current, total, message?}`；done 见 §5.1 |
| `file-hasher:config`  | sync | `{}`                                | `{algorithms: Algorithm[]}`（缺省 `['sha256']`，存量非法回落默认）                          |
| `file-hasher:set-config` | sync | `{algorithms: Algorithm[1..3]}`  | 同 `config`                                                                                |

### 5.1 done 形状

```
{
  results: {
    path, size, mtimeMs,
    hashes: { md5?, sha1?, sha256? },
    status: 'ok' | 'failed',
    code?, message?
  }[],
  failedCount, totalBytes, elapsedMs
}
```

**批量语义**：单文件失败不中断整批；取消由壳 terminate worker，队列终态 `CANCELLED`。

## 6. 错误码

| 码                    | 中文文案                                                     | 可重试 |
| --------------------- | ------------------------------------------------------------ | ------ |
| `FH_FILE_INVALID`     | 无法读取文件（不存在、非普通文件、超过 20 GB 或无权限）      | 是     |
| `FH_HASH_FAILED`      | 计算失败，文件可能被占用或读取中断                           | 是     |
| `FH_INVALID_PAYLOAD`  | 参数无效                                                     | 否     |
| `CANCELLED`           | 任务已取消（壳统一）                                         | 否     |

## 7. 三态要求（AGENTS §5.3）

| 状态   | 表现                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| 空态   | 拖拽区 + 「添加文件后点击『开始校验』，即可获得哈希值」；已选未执行时提示点击开始       |
| 加载态 | 阶段文案 + 已处理/总字节 + 当前文件名 + [取消]（R4 可取消）                            |
| 报错态 | 结构化错误码 → 中文文案 + [重试]（仅 `FH_FILE_INVALID`/`FH_HASH_FAILED`）+ [详情]折叠  |

## 8. 比对语义

- 归一：trim → 去全部空白 → 小写 → 去 `0x` → 剥离前缀（`md5:`/`sha1:`/`sha-1:`/`sha256:`/`sha-256:`）。
- 无前缀按长度识别：32 → md5、40 → sha1、64 → sha256；长度不符或含非十六进制字符 → 格式非法。
- 命中判定：该行 `status='ok'` 且**对应算法**摘要与期望值相等；其它算法不参与。
- 比对纯前端完成（renderer 纯函数），不进 IPC。

## 9. 验收断言

1. `abc` 三算法结果等于 RFC 测试向量（`900150…` / `a9993e…` / `ba7816…`）。
2. 中文 + 空格路径全链路无损；结果保持入参顺序。
3. 缺失/目录/超 20GB/ACL 拒读 → 该行失败且错误码正确，其余文件照常完成。
4. 取消 → 终态 `CANCELLED`（快速完成时为 `done`），无残留任务。
5. 期望哈希（带前缀/大写/带空格）命中行高亮 + 「匹配」；长度/字符非法红字提示。
6. 复制单行/复制全部为 TSV（含表头，列 = 已选算法）。
7. R2 八类异常逐条实测记录于 `docs/smoke/file-hasher.md`。
