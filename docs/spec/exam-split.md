> 工具 id：`exam-split` · 显示名：**试卷切割** · 包：`@lumin/tool-exam-split` · 图标：`scissors`
> 本清单覆盖 **M3a（PDF 操作）**；M3b（OCR 切题）开工时另行增补 §10，双 Tab 形态已定（plan §3 同包两入口）。

## 1. 输入项

| 字段         | 类型                                                           | 约束                                                                                                        | 默认值                           |
| ------------ | -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | -------------------------------- |
| 输入文件     | 文件路径（拆分/删页/旋转/裁剪=单选，合并=多选，accept `.pdf`） | 必须存在、可读、未被独占占用、`%PDF-` 头可解析；合并列表 **2–100** 个（zod max）                            | 无                               |
| 页码区间     | string（拆分必填；删页/旋转/裁剪选填）                         | 语法 `1-3,5,7-9`（仅数字/逗号/连字符/空白）；范围以实际页数为界，越界或语法错 → `RANGE_INVALID`             | 空 = 全部页（删页除外，见 §3.2） |
| 合并文件列表 | 有序列表（渲染端状态）                                         | 拖拽排序 + 每项 [上移][下移][移除]；至少 2 项才可执行                                                       | 无                               |
| 旋转角度     | enum `90 \| 180 \| 270`                                        | 度数（顺时针）                                                                                              | `90`                             |
| 裁剪框       | `{x, y, width, height}`（mm，左上原点）                        | 宽高 > 0；以**当前预览页**为参照录入，内部归一化为 0–1 比例，逐页按各自 MediaBox 等比应用（混排页尺寸安全） | 整页                             |

- 预览读文件走 **`File.arrayBuffer()` 直读**（renderer 内，不经 IPC）；主进程操作走**路径 payload**。
- 无工具设置项（settings 不新增键）。

| 区域         | M3a 呈现                                                                                       |

## 3. 操作与按钮集

### 3.1 通用

| 操作       | 行为                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------- |
| 选择/拖拽  | DropZone（`multiple` 仅合并模式）→ `bridge.getPathForFile` 取真实路径；非 `.pdf` 拒绝提示 |
| 开始处理   | 前端区间初校 → 提交对应 task 通道；排队中与执行中均可**取消**                             |
| 取消       | 通用 `lumin:task:cancel`；执行中 = `worker.terminate()` 硬终止（无半成品，见 §7）         |
| 打开文件夹 | `bridge.revealPath(产物路径)`                                                             |
| 再处理一个 | 清结果卡与字段（预览与 Tab 保留），回可执行态                                             |

### 3.2 五操作字段矩阵

| 操作 | 必填字段                                  | 可选字段                     | 产物（同目录，命名见 §7）             |
| ---- | ----------------------------------------- | ---------------------------- | ------------------------------------- |
| 拆分 | 输入文件、页码区间（每区间一文件）        | —                            | N 个（N=区间数）                      |
| 合并 | ≥2 个文件（有序）                         | —                            | 1 个                                  |
| 删页 | 输入文件、页码区间（=要删的页，**必填**） | —                            | 1 个；删后剩余 0 页 → `NO_PAGES_LEFT` |
| 旋转 | 输入文件                                  | 页码区间（默认全部）、角度   | 1 个                                  |
| 裁剪 | 输入文件                                  | 页码区间（默认全部）、裁剪框 | 1 个                                  |

- 拆分/删页的区间均做**重复页校验**：拆分区间互相重叠 → `RANGE_INVALID`（detail=`overlap`）；删页重复页自动去重。

## 4. IPC 契约（zod 校验，schema 随工具包）

| 通道                | 类型 | 入参                                              | 事件                                                                                                                  |
| ------------------- | ---- | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `exam-split:split`  | task | `{ inputPath, ranges }`                           | `progress { stage: 'load'\|'process'\|'write'\|'done', current, total?, message }` · `done { outputPaths }` · `error` |
| `exam-split:merge`  | task | `{ inputPaths: string[2..100] }`                  | 同上（`current/total` = 已合并文件数）                                                                                |
| `exam-split:delete` | task | `{ inputPath, ranges }`                           | 同上                                                                                                                  |
| `exam-split:rotate` | task | `{ inputPath, ranges?, degrees: 90\|180\|270 }`   | 同上                                                                                                                  |
| `exam-split:crop`   | task | `{ inputPath, ranges?, box: {x,y,width,height} }` | 同上                                                                                                                  |
| 取消                | 通用 | 任务 id                                           | `error { code: 'CANCELLED' }`                                                                                         |

- **执行模型**：全部任务经 node-kit `runTask()` 进 **worker_threads**（electron-vite `?modulePath`，spike §2）；worker 单文件 `pdf.worker.ts` 内分发五算子；进度经 `postMessage` 上抛。
- **进度阶段**：`load(0)` → `process(1)` → `write(2)` → `done(3)`；merge 的 process 按文件推进 `current=1..N`。
- **超时**：自任务执行起 **120s**，超时 `terminate()` → `OP_TIMEOUT`。
- **并发**：壳全局队列（默认 2，`shell.taskConcurrency`）即为 PDF 并发上限（plan §2.2「PDF 2」）；工具内**无互斥**（无外部程序锁）。
- pdf-lib 写出为**内存直写目标路径**（无临时目录、无 move，规避跨盘与残留）；预检 `open('r')` 语义同 docx2pdf（EBUSY/EPERM/EACCES → 占用）。

## 5. 错误码 → 中文文案（结构化错误，detail 附上下文 ≤2000 字符）

| 错误码                | 触发条件                                                                         | 中文文案                                   | 操作入口    |
| --------------------- | -------------------------------------------------------------------------------- | ------------------------------------------ | ----------- |
| `PDF_NOT_FOUND`       | 预检：输入文件不存在/已移动                                                      | 输入文件不存在，请重新选择                 | 重新选择    |
| `PDF_LOCKED`          | 预检：`open('r')` 独占打开失败（EBUSY/EPERM/EACCES）                             | 文件被其他程序占用，请关闭后重试           | 重试        |
| `PDF_ENCRYPTED`       | pdf-lib load 消息含 `is encrypted`（spike §4）；预览侧 pdfjs `PasswordException` | PDF 已加密，请先解除密码再操作             | 重新选择    |
| `PDF_INVALID`         | load 抛非加密类错误（结构损坏/非 PDF/截断）                                      | 文件无法读取（可能已损坏或非 PDF 文件）    | 详情        |
| `RANGE_INVALID`       | 区间语法错、越界（>页数）、拆分区间重叠                                          | 页码区间无效，请检查（如 1-3,5）           | 重新输入    |
| `NO_PAGES_LEFT`       | 删页后剩余 0 页                                                                  | 至少保留一页，已取消操作                   | 重新输入    |
| `OP_TIMEOUT`          | 执行 120s 未完成 → terminate                                                     | 处理超时（120 秒），已终止                 | 重试        |
| `OUTPUT_WRITE_FAILED` | 写产物失败（errno 入 detail）或命名冲突 99 次耗尽（detail=`conflict-exhausted`） | 无法写出结果文件，请检查目录权限与剩余空间 | 重试        |
| `OP_FAILED`           | worker 意外异常（detail=错误消息尾部）                                           | 处理失败，请重试或查看详情                 | 重试 + 详情 |
| `CANCELLED`           | 排队中/执行中取消                                                                | 已取消                                     | —           |
| `INVALID_PAYLOAD`     | zod 校验失败                                                                     | 参数无效                                   | —           |

- Error 实例**不透传**（M2 教训：`isStructuredError`/`toStructuredError` 已修复，沿用 plain object `toolError` 模式）。

## 7. 输出策略

1. 产物一律写**输入文件同目录**（合并 = 首个输入文件所在目录），不建临时目录、不 move。
2. 命名模板：
   - 拆分：`{原名}_p{标签}.pdf`（标签规范化：`1-3` → `p1-3`、单页 `5` → `p5`，按区间顺序逐个产出）
   - 合并：`{首个原名}_合并.pdf`　删页：`{原名}_删p{标签}.pdf`
   - 旋转：`{原名}_旋转{90|180|270}.pdf`　裁剪：`{原名}_裁剪.pdf`
3. 冲突递增：`…(1)`、`…(2)` … 上限 `(99)`；耗尽 → `OUTPUT_WRITE_FAILED`（detail=`conflict-exhausted`）。
   **冲突递增逻辑上提 `@lumin/node-kit`**（docx2pdf 同步重构为调用方，行为与既有测试不变——AGENTS 铁律 3）。
4. 产物校验（写后）：size>0 且头 5 字节 `%PDF-`；不满足 → `OUTPUT_WRITE_FAILED`。

## 8. 验收（plan §4.4 M3a / R5）

- **100 页拆分 < 2s**：✅ 集成断言通过（pdf-lib 生成 100 页 fixture → 拆分 `elapsed < 2000ms`）；e2e 百页卷 `_p1`/`_p100` 产物 `%PDF-`。
- **区间解析纯函数 ≥80%**（`parseRanges`/标签规范化/重叠检测，coverage 分组强制）；全仓 ≥60%。✅ 终验：exam-split 分组 **96.42% stmts / 83.8% branches / 96.92% fns / 98.31% lines**；全仓 92.94% stmts / 86.39% branches。
- **chunk（R5，2026-11-14 口径）**：✅ 最终实测 `exam-split-*.js` raw 843.6KB / **gzip 189.5KB < 200KB**（P0 预估 ≈150KB，最终含 pdfjs 主库）；**pdfjs worker 资产单列**（raw 1,242.1KB / gzip 370.4KB，不计入上限，见 `docs/smoke/exam-split.md` §4）；pdf-lib 走主进程 worker 不属 R5 口径。
- **R2 八类**：✅ `docs/smoke/exam-split.md` 逐条真实记录（1/2/3/5/6/8 e2e、4 超大 74.7MB 脚本实测、7 磁盘满 VHD ENOSPC 实测）。
- 人工目视：✅ 拆分/删页/旋转产物 soffice 转 PNG 核对（页序、方向、无豆腐块）；裁剪产物因 LibreOffice 忽略 CropBox，改用工具 pdfjs 预览渲染截图核对裁剪区域（CropBox 数值 `{59.5,84.2,476.2,673.5}` 精确、文字被裁仅剩分隔线）。
