# Vibe Coding Skills - End User

- 需求一句话精准讲清，不模糊、不脑补、不中途临时变卦
- 明确知道自己要什么、不要什么，拒绝被产品/研发随意阉割功能
- 能用业务视角精准验收，一眼识别功能缺漏、逻辑敷衍、体验缩水
- 拒绝“能用就行”，抠细节、抠流程、抠交互感受，不达预期直接打回
- 清晰描述问题复现步骤，不笼统吐槽，给AI和研发精准修复依据
- 坚守原始需求边界，抵制研发擅自简化、偷工减料、变更初衷
- 能看懂基础原型与功能流程，不被专业话术忽悠妥协
- 坚持体验一致性，页面风格、操作逻辑不允许各做各的
- 善于发现隐藏bug、边缘场景、异常流程，不被表面正常蒙骗
- 拒绝频繁返工折腾，一次性把诉求说透，卡死交付标准
