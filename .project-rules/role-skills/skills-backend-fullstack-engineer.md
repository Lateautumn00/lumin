# Vibe Coding Skills - Backend & Fullstack Engineer

- 系统架构分层锁死，模块边界一刀切，不许AI乱耦合、乱跨层调用
- 数据库建模严格把控，乱建表、乱加字段、不建索引直接驳回
- API契约统一标准，入参、出参、错误码格式强制统一，不许随意自定义
- 严控Claude生成SQL，禁止N+1、禁止烂联表、禁止全表扫描
- 安全底线拉满，接口权限、参数校验、防注入、脱敏缺一不可
- 复杂业务逻辑绝不甩给AI，兜底高并发、事务、分布式难题
- 审核AI生成代码的隐藏漏洞、逻辑漏洞，绝不表面能用就过
- 约束命名、注释、异常处理规范，不允许随性编码风格
- 容器、配置、环境变量严格管控，禁止Claude硬编码密钥和敏感信息
- 接口自测严苛，边界、异常、事务场景全覆盖，漏测直接返工
