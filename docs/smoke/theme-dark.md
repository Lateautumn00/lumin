# theme-dark（深色主题切换）冒烟记录

> 能力：壳级平台能力（M19，2026-11-19）· 规格：`docs/spec/theme-dark.md`
> 自动化：`apps/desktop/e2e/theme-smoke.spec.ts`（3 用例）
> 环境：Windows x64 · Electron 45.3.1 · 本地离线
> 结论：三模式切换、tokens 计算值、持久化与重启恢复全部通过；无新增依赖、无新增 IPC。

## 1. 自动化结果（e2e 3 用例）

| #   | 用例                     | 断言                                                                                                                            | 结果 |
| --- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 1   | 默认跟随系统             | 持久化预置 `system` 后重载：设置页「跟随系统」选中；`html[data-theme]` 与 `matchMedia('(prefers-color-scheme: dark)')` 一致       | 通过 |
| 2   | 切深色/浅色              | 深色：单选选中、`data-theme='dark'`、`--lumin-color-bg=#0b1220`、`--lumin-color-text=#e2e8f0`、body 背景 `rgb(11,18,32)`、settings 写入 `dark`；浅色：复原 `#f8fafc` 并写入 `light` | 通过 |
| 3   | 重启保持深色             | 切深色并确认落盘 → 关闭应用 → 重新启动 → 设置页仍选中「深色」、`data-theme='dark'`、token 为暗色；结束写回 `system` 清场             | 通过 |

## 2. R2 八类异常逐条

| 类别             | 场景与验证                                                                                                       | 结果   |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- | ------ |
| 1. 中文/空格路径 | 不适用（主题为设置键读写，不涉及文件路径）；settings.json 位于 userData，路径由 Electron 解析                     | 不适用 |
| 2. 文件被占用     | settings 服务已具备 EPERM/EACCES 短重试 + 写队列（M6 加固）；持久化失败用例见单测 `写入失败回滚`                   | 通过   |
| 3. 加密文件       | 不适用（无文件内容处理）                                                                                         | 不适用 |
| 4. 超大文件       | 不适用（无文件内容处理）                                                                                         | 不适用 |
| 5. 任务取消       | 不适用（无长任务）；切换期间单选组禁用，避免并发写竞态                                                            | 不适用 |
| 6. 并发溢出       | 单测覆盖「写入失败回滚」；settings 写队列串行，连点由 `themeSaving` 禁用                                           | 通过   |
| 7. 磁盘满         | 持久化失败 → 回滚模式 + 设置页中文错误提示（`主题切换失败：…`），不崩溃                                           | 通过   |
| 8. 断电恢复       | 模式在点击时原子落盘（临时文件 + rename）；重启 e2e 用例 3 验证恢复；损坏 JSON 由 settings 服务回落默认值 `system` | 通过   |

## 3. 人工目视项

- 深色下设置页、侧边栏、计算器页无白底区块（e2e 用例 2 以 body 背景与工具页 token 断言替代人工截图）。
- Naive 组件（按钮/输入框/单选/弹窗）随 `darkTheme` 切换，无需组件内覆盖；设置页、关于页在深色下文字对比正常。
- 例外：PDF/图片预览画布保持白色（内容本身为白底），不属于页面缺陷。

## 5. 设置键

- `shell.theme.mode`：`system | light | dark`，默认 `system`，非法存量回落 `system`（单测覆盖）。
- e2e 每个用例开始均预置 `system` 并重载，保证与执行顺序无关。
