# Lumin v0.9.0 — 首个公开发布

> 发布日期：2026-11-19 · 平台：Windows x64（10/11） · 许可：MIT

Lumin 是离线优先的 Windows 桌面实用工具箱：单窗口侧边栏、工具独立可插拔、无自建后端、数据不出本机。首发版包含 8 个工具与完整自动更新链路。

## 首发能力

| 工具 | 能力 |
| --- | --- |
| 计算器 | 表达式求值 + 历史记录 |
| 单位换算 | 10 类单位（不含汇率） |
| Office 转 PDF | `.doc/.docx/.xls/.xlsx/.ppt/.pptx` 批量转 PDF，同目录输出、重名自动 `(1)` |
| 试卷切割 | PDF 拆分/合并/删页/裁剪 + OCR 切题 |
| 图片工具箱 | 压缩 / 格式转换 / 缩放（JPG/PNG/WebP/AVIF/BMP/TIFF，GIF→WebP 保留动画） |
| 批量重命名 | 六规则叠加、实时预览、冲突检测、单次撤销 |
| 文本工具箱 | JSON 格式化/压缩/校验、Base64/URL 编解码、正则测试与替换 |
| 视频下载 | B 站/抖音/YouTube 等，Cookie 支持，免责三重提示 |

## 安装

1. 下载对应安装包；
2. 未签名版本首次运行会触发 SmartScreen：**更多信息 → 仍要运行**；
3. 校验完整性（可选）：

```powershell
Get-FileHash .\Lumin-0.9.0-win-x64-setup.exe -Algorithm SHA256
```

4. Office 转 PDF 首次使用在工具页内一键下载 LibreOffice 便携组件（约 359 MB），或指定本机 `soffice.exe`。

## 自动更新

- 更新源：`https://gitee.com/Lateautumn00/lumin/raw/master/updates`（generic provider）
- 关于页「检查更新」→ 下载 →「安装并重启」；`allowDowngrade=false`，回滚通过发布新版本覆盖
- 发布新版本时需同时上传：安装包、`.blockmap`、`latest.yml` 到 `updates/` 目录

## 已知限制

- 无代码签名证书：SmartScreen 提示按上文操作
- 便携版自更新后写入原路径；若放在只读介质需换用安装版
- 视频下载需联网，请遵守目标平台条款与版权；仅限下载你有权保存的内容
- **发布包体积**：本版随包 OCR 模型（≈15.5MB）与 yt-dlp/ffmpeg/ffprobe（≈180MB），setup ≈290MB、portable ≈261MB。若 Gitee 仓库/Release 的单文件限制不足，按 plan §5.3 切换对象存储托管安装包，仅改 `electron-builder.yml` `publish.url` 与 `updates/latest.yml` 的下载地址（代码零改动）

## 校验值

发布时由 CI/本地 `Get-FileHash -Algorithm SHA256` 生成并填入本节（当前为空模板，禁止凭记忆填值）。
