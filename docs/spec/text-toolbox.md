# 文本工具箱（text-toolbox）字段级功能清单

> 版本：v0.4.0 · 定稿日期：2026-11-21（R8）· 工具 id：`text-toolbox`
> 本文件为该里程碑验收附件；实现与本文件不一致时以本文件为准，变更须走 R8 流程。

## 1. 范围与边界

**做**：JSON 格式化 / 压缩 / 校验（含错误行列定位）、Base64 / URL Component / Hex / Unicode 编解码、正则测试与替换预览、批量文本处理（替换 / 清空空白行 / 去重 / 排序 / 大小写）、字数统计（字符 / 汉字 / 字母 / 数字 / 词 / 行 / UTF-8 字节）、摩尔斯电码编解码（字母 / 数字 / 常用标点）、CSV ↔ JSON 双向转换（RFC 4180 引号 / 转义，分隔符与表头可配）。

**不做**：哈希计算、文本 diff、语法高亮、文件读写（纯剪贴板/输入框文本）、联网能力、CSV 类型推断（CSV → JSON 的值一律为字符串）。

**形态**：纯 renderer 工具，**零 IPC、零新增第三方依赖**（仅复用 naive-ui/@lucide/vue/vue）。

## 2. 页面字段清单

页签为 `JSON / 编解码 / 正则 / 文本处理 / 摩尔斯 / CSV/JSON`；页签仅作切换器，内容区随 `v-if` 渲染（非活动页签不挂载）。

### 2.1 JSON Tab

| 区域   | 控件                    | 行为                                                              | 空/默认              |
| ------ | ----------------------- | ----------------------------------------------------------------- | -------------------- |
| 选项行 | 缩进下拉（原生 select） | `2 空格 / 4 空格`，仅影响「格式化」                               | 2 空格               |
| 输入区 | 多行文本域              | placeholder「粘贴 JSON 文本」；支持「填入示例」                   | 空                   |

| 操作区 | [格式化] [压缩] [校验]  | 见 §3.1；输入为空 → 提示「请先输入 JSON 文本」                    | 可点（空输入仅提示） |

| 操作区 | [编码] [解码] [交换]                                                             | 「交换」把输出内容回填输入并清空输出；无输出时禁用                                                              | 可点（空输入仅提示） |

| 区域   | 控件                                                                      | 行为                                                                                                                          | 空/默认  |

### 2.4 文本处理 Tab（M36）

| 区域      | 控件                                                                           | 行为                                                                                   |
| --------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| 替换行    | 查找 / 替换为 输入 + `正则` / `区分大小写` 勾选 + `[替换]`                     | 空查找 → `TT_REPLACE_INVALID`；非法正则 → `TT_REGEX_INVALID`；字面量模式自动转义元字符 |
| 行处理行  | `清空空白行` / `去重` 勾选 + 排序下拉 + 大小写下拉 + `[处理行]`                | 固定顺序：去空行 → 大小写 → 去重 → 排序；`[填入示例]` / `[清空]`                       |
| 输入/输出 | 双栏多行文本域                                                                 | 输出只读 + `[复制]`；输入改动后输出视为过期，统计回落到输入                            |
| 统计区    | 9 个卡片：字符 / 不含空白 / 汉字 / 字母 / 数字 / 词 / 行 / 非空行 / UTF-8 字节 | 实时统计（处理过则统计输出，否则统计输入）；字符按码点计，emoji 记 1                   |

### 2.5 摩尔斯 Tab（M44）

| 区域   | 控件                                                          | 行为                                                                                       | 空/默认              |
| ------ | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | -------------------- |
| 输入区 | 多行文本域                                                    | placeholder「输入文本或摩尔斯码（字母空格分隔，单词用 / 分隔）」；支持「填入示例」         | 空                   |
| 输出区 | 只读多行文本域 + [复制]                                       | placeholder「处理结果」                                                                    | 空                   |
| 操作区 | [编码] [解码] [交换]                                          | 编码不区分大小写、单词用「 / 」分隔；解码结果统一大写；不支持的字符/未知码 → `TT_MORSE_INVALID` | 可点（空输入仅提示） |
| 说明行 | 文本                                                          | 「支持 A–Z、0–9 与常用标点；编码不区分大小写，解码结果统一为大写。」                       | 固定                 |

- 支持字符集：`A–Z`、`0–9` 与 `. , ? ' ! / ( ) & : ; = + - _ " $ @`（ITU 标准码表）。
- 单词分隔统一为「 / 」（`\s*/\s*` 容错）；字母间单空格，连续空白归一。

### 2.6 CSV/JSON Tab（M47）

| 区域   | 控件                                                                 | 行为                                                                                         | 空/默认 |
| ------ | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------- |
| 方向行 | 方向下拉 `CSV → JSON / JSON → CSV` + 分隔符下拉 `逗号 / 制表符 / 分号 / 竖线` | 切换方向清空提示；CSV → JSON 显示「首行作为表头」；JSON → CSV 显示「输出表头」             | CSV → JSON / 逗号 |
| 输入区 | 多行文本域                                                           | placeholder 随方向变化；支持「填入示例」                                                     | 空      |
| 输出区 | 只读多行文本域 + [复制]                                              | placeholder「转换结果」                                                                      | 空      |
| 操作区 | [转换] [交换]                                                        | 「交换」输出回填输入并反转方向；无输出时禁用；空输入仅提示「请先输入要转换的文本」           | 可点    |
| 选项行 | `首行作为表头` / `输出表头` 勾选                                     | 前者决定 CSV → JSON 输出对象数组还是二维数组；后者决定 JSON → CSV 是否输出表头行             | 均勾选  |

- 方向为 CSV → JSON：首行作表头时输出 `[{列名: 值}]`（值一律字符串），否则输出 `[["a","b"]]`。
- 方向为 JSON → CSV：输入须为**扁平对象数组**；列名取所有对象 key 的首次出现顺序；`null`/缺失字段输出空；数字与布尔转字面量；行列以 `\r\n` 结束。
- 空行忽略；CSV 首部 BOM 自动去除。

## 3. 纯函数契约（`src/*.ts`，≥80% 覆盖）

### 3.1 JSON（`json.ts`）

| 函数                     | 入参       | 成功值      | 失败                                                         |
| ------------------------ | ---------- | ----------- | ------------------------------------------------------------ |
| `parseJson(text)`        | 文本       | 解析值      | `TT_JSON_INVALID`（detail 含「第 X 行第 Y 列」）+ `position` |
| `formatJson(text, 2\|4)` | 文本、缩进 | 格式化串    | 透传 parse 错误                                              |
| `minifyJson(text)`       | 文本       | 压缩串      | 透传 parse 错误                                              |
| `validateJson(text)`     | 文本       | `{ bytes }` | 透传 parse 错误                                              |

- 位置换算：V8 消息 `at position N` → 1 基行列（列按 UTF-16 码元）；无 position（`Unexpected end of JSON input` 等）→ 定位到文本末尾。
- 全部入口先做 5MB 字节校验（`TT_TEXT_TOO_LARGE`）。

### 3.2 编解码（`encoding.ts`）

| 函数                  | 行为                                                                                                                                     |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `encodeBase64(text)`  | TextEncoder → 32KB 分片 `btoa`（防参数展开爆栈）                                                                                         |
| `decodeBase64(text)`  | 去空白 → 字符集 `/^[A-Za-z0-9+/]*={0,2}$/`、长度 %4≠1 → `atob` → `TextDecoder('utf-8', { fatal: true })`；非 UTF-8 → `TT_BASE64_INVALID` |
| `encodeUrl(text)`     | `encodeURIComponent`；孤立代理项等失败 → `TT_URL_INVALID`                                                                                |
| `decodeUrl(text)`     | `decodeURIComponent`；非法百分号 → `TT_URL_INVALID`                                                                                      |
| `encodeHex(text)`     | TextEncoder → 每字节两位小写十六进制、空格分隔                                                                                           |
| `decodeHex(text)`     | 去空白 → 仅十六进制字符、长度偶数 → `TextDecoder('utf-8', { fatal: true })`；非法字符/奇数长度/非 UTF-8 → `TT_HEX_INVALID`               |
| `encodeUnicode(text)` | 每个 UTF-16 码元输出 `\uXXXX`（大写，代理对拆两段）                                                                                      |
| `decodeUnicode(text)` | 逐个识别 `\uXXXX`，其余字符原样保留；转义不完整 → `TT_UNICODE_INVALID`                                                                   |

### 3.3 正则（`regex.ts`）

| 函数                                                             | 行为                                                                                                               |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `compileRegex(pattern, flags)`                                   | `new RegExp`；失败 → `TT_REGEX_INVALID`（带原生消息）                                                              |
| `collectMatches(pattern, flags, text, limit=500)`                | 空模式 → 0 匹配；无 `g` 只取首条；零长度匹配 `lastIndex++` 防死循环；超上限 `truncated=true` 且 `total` 为已扫描数 |
| `replacePreview(pattern, flags, text, replacement, limit=10000)` | 无 `g` 只替换首条；零长度匹配防死循环；`count` 为扫描替换次数、`truncated` 标记超限                                |

### 3.4 文本处理与统计（`text-ops.ts` / `stats.ts`）

| 函数                                                             | 行为                                                                                             |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `replaceText(text, find, replacement, { regex, caseSensitive })` | 空查找 → `TT_REPLACE_INVALID`；字面量自动转义；正则编译失败 → `TT_REGEX_INVALID`；返回替换后文本 |
| `convertCase(text, 'upper'\|'lower'\|'title'\|'none')`           | title：先小写，再把每个单词首字母大写（字母/数字之外为分隔）                                     |
| `applyLineOps(text, { removeEmpty, dedupe, sort, caseMode })`    | 固定顺序：去空行 → 大小写 → 去重 → 排序（`localeCompare` + numeric）；空文本返回空串             |
| `countText(text)`                                                | `{ chars, charsNoSpaces, chinese, letters, digits, words, lines, nonEmptyLines, bytes }`         |

统计口径：`chars` 按 Unicode 码点；`chinese` 为 `\p{Script=Han}`；`letters` 为 `\p{L}` 去掉汉字；`digits` 为 `\p{N}`；`lines` 按 CRLF/CR/LF 拆分（空文本 0 行）；`bytes` 为 UTF-8 字节。

### 3.5 摩尔斯（`morse.ts`，M44）

| 函数                | 行为                                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------------------------- |
| `encodeMorse(text)` | 大写归一后按码表逐个转换；字母单空格、单词「 / 」；空/纯空白 → 空串；不支持字符 → `TT_MORSE_INVALID`（detail 带字符） |
| `decodeMorse(text)` | 按「 / 」分单词、空白分字母；未知码 → `TT_MORSE_INVALID`（detail 带码）；空串 → 空串；输出大写             |

- 码表为 ITU 标准：`A–Z`、`0–9` 与 `. , ? ' ! / ( ) & : ; = + - _ " $ @`；反向表由正向表一次生成。
- 全部入口先做 5MB 字节校验（`TT_TEXT_TOO_LARGE`）。

### 3.6 CSV ↔ JSON（`csv.ts`，M47）

| 函数                                                       | 行为                                                                                                                     |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `parseCsv(text, { delimiter=',', hasHeader=true })`        | RFC 4180 解析：引号包裹、`""` 转义、字段内换行；`\r\n`/`\r` 归一为 `\n`；空行忽略；列数不一致 / 引号未闭合 / 表头重复 → `TT_CSV_INVALID`（detail 带行号） |
| `csvToJson(text, options)`                                 | 有表头 → `[{列名: 值}]`；无表头 → `[["a","b"]]`；输出 2 空格缩进 JSON                                                       |
| `jsonToCsv(text, { delimiter=',', includeHeader=true })`   | `parseJson` 解析 → 必须为对象数组（非法 JSON 透传 `TT_JSON_INVALID`）；嵌套对象/数组 → `TT_CSV_INVALID`；字符串含分隔符/引号/换行时加引号并双写 `"`；列间用分隔符、行间 `\r\n` |

- `delimiter` 取值仅 `,` / `\t` / `;` / `|`；表头重复或列数不一致均直接报错，不做静默补空。
- 所有 CSV 入口先做 5MB 字节校验（`TT_TEXT_TOO_LARGE`）。

## 4. 三态与限制

| 状态   | 实现                                                                                                  |
| ------ | ----------------------------------------------------------------------------------------------------- |
| 空态   | 各 Tab 输入/输出文本域 placeholder + 「填入示例」；正则匹配区空态文案                                 |
| 加载态 | 输入 >200KB 时先置「处理中」再 `setTimeout(0)` 分帧执行（同步计算无可取消任务，按 spec 声明豁免取消） |
| 报错态 | 结构化错误码 → 中文文案 + detail 折叠展示（JSON 含行列）                                              |

- 单次处理文本上限 **5MB**（UTF-8 字节），超限 `TT_TEXT_TOO_LARGE`。
- 匹配/替换扫描上限 **500 / 10000**，超限标注截断，避免渲染进程卡死。

## 5. 错误码

| 码                    | 中文文案                      | 触发来源                           |
| --------------------- | ----------------------------- | ---------------------------------- |
| `TT_JSON_INVALID`     | JSON 格式不正确               | JSON Tab 解析失败（detail 带行列） |
| `TT_TEXT_TOO_LARGE`   | 文本超过 5MB 上限，请分段处理 | 所有入口的字节校验                 |
| `TT_BASE64_INVALID`   | 不是有效的 Base64 文本        | 非 Base64 字符集/长度/非 UTF-8     |
| `TT_URL_INVALID`      | 不是有效的 URL 编码文本       | 非法百分号编码 / 无法编码字符      |
| `TT_REGEX_INVALID`    | 正则表达式不正确              | 模式或 flags 非法                  |
| `TT_HEX_INVALID`      | 不是有效的十六进制文本        | 非十六进制字符/奇数长度/非 UTF-8   |
| `TT_UNICODE_INVALID`  | 不是有效的 Unicode 转义文本   | `\u` 后不是 4 位十六进制           |
| `TT_REPLACE_INVALID`  | 查找内容不能为空              | 文本处理 Tab 空查找                |
| `TT_MORSE_INVALID`    | 不是有效的摩尔斯电码文本      | 编码遇不支持字符 / 解码遇未知码    |
| `TT_CSV_INVALID`      | CSV/JSON 数据格式不正确       | 列数不一致 / 引号未闭合 / 表头重复 / JSON 非对象数组 / 嵌套值 |
| `TT_CLIPBOARD_FAILED` | 复制失败，请手动选择文本复制  | 渲染层剪贴板写入失败（UI 兜底）    |

## 6. R5 体积口径

工具 chunk `text-toolbox-*.js` 实测 **77,047 B raw / 16,663 B gzip**（M47）；独占依赖 chunk 为 0（naive-ui Tabs/Button 等为多工具共享 vendor，不计入增量）。
