# image-stitch（图片拼接）冒烟记录

> 工具：`image-stitch`（M22，2026-11-20）
> 规格：`docs/spec/image-stitch.md` · 自动化：`apps/desktop/e2e/image-stitch-smoke.spec.ts`
> 手工复现环境：Windows x64 · Electron 壳 · 本地离线 · `@napi-rs/canvas` 1.1.1（随包原生库）
> 结论：八类异常全部有覆盖路径；渲染 → worker（两遍）→ 落盘全链路由 e2e 真实执行，原图不变、冲突递增与取消无残留已断言。

## 2. R2 八类异常逐条

| 类别             | 场景与验证                                                                                                                                                        | 结果 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 1. 中文/空格路径 | 用例 1：输入 `照片 1.png`、输出目录 `输出 目录`、产物 `拼接_20261120-*.png` 全链路可读写                                                                             | 通过 |
| 2. 文件被占用     | 单测 `node.test.ts`：`checkExclusive` 抛 `EBUSY` → `IS_FILE_LOCKED`（detail 保留 errno）；`ENOENT` → `IS_INPUT_INVALID`；e2e 未构造真实独占（图片查看器通常共享读）        | 通过 |
| 3. 加密文件       | 不适用（位图无解密语义）；伪装 `.png` 的加密容器与用例 2 损坏图同分支 → `IS_IMAGE_CORRUPT`（e2e 实测）                                                                | 不适用 |
| 4. 超大文件       | 用例 2：41MB → renderer 预检跳过并提示；单测 `node.test.ts`：`statSize > 40MB` → `IS_IMAGE_TOO_LARGE`（预检拒绝、不启动 worker）；另有 `IS_OUTPUT_TOO_LARGE`（20000×20000×2 → 总高 40000px 超 30000px 上限）单测 | 通过 |
| 5. 任务取消       | 用例 2：提交 1600×1200 图后立即 `lumin:task:cancel` → `CANCELLED` 事件；输出目录无 `.tmp`；UI 加载态「取消」走同一通道                                                  | 通过 |
| 6. 并发溢出       | 单测 `schema.test.ts`：101 张 → 拒绝；同名冲突递增（`拼接_…png` 占位 → `拼接_… (1).png`）由 worker 单测 + e2e 双覆盖；多任务并发由壳队列上限串行控制                     | 通过 |
| 7. 磁盘满         | 单测 `stitch.worker.test.ts`：输出目录被同名文件占位 → `IS_WRITE_FAILED`；写盘为 `.tmp` + rename，失败 best-effort 清理临时文件；未做 ENOSPC 定向实测（说明见 §3） | 通过 |
| 8. 断电恢复       | `.tmp` + rename 保证目标文件要么不存在要么完整；解码失败不产生半成品；e2e 未强杀（说明见 §3）                                                                     | 通过 |

## 3. 不可实测项说明

- **真实文件占用**：Windows 图片查看器以共享读打开，稳定制造 EBUSY 成本高；占用映射由单测覆盖同一代码路径。
- **磁盘满**：未建 VHD 定向模拟 ENOSPC；写失败分支由「输出目录被文件占位」单测覆盖（同一 `IS_WRITE_FAILED` 映射）。
- **断电恢复**：原子写语义由 `.tmp` + rename 实现与取消用例保证；e2e 强杀会破坏 Playwright 会话，未纳入。
- **EXIF 方向**：`@napi-rs/canvas` 解码按内建行为输出；本里程碑未纳入带 EXIF 方向的样图（人工补测项，不改依赖）。

## 7. M40 长图分割（2026-11-21）

### 7.1 功能与验收

- **入口**：`image-stitch` 新增「长图分割」页签（单图），页签「拼接」行为不变。
- **通道**：`image-stitch:split`（task，`split.worker.ts`）；`{inputPath, mode:'height'|'parts', height 50–30000, parts 2–50, quality 60–100, outputDir?}` → done `{outputs[{path,width,height}], sourceWidth, sourceHeight}`。
- **切分口径**：固定高度按 `ceil(高/高度)` 等分、末段保留实际高；按份数 `base=floor(高/份数)`，余数摊到前几段；份数 > 图高、段数 >100、源图 >30000px → `IS_SPLIT_INVALID`。
- **命名**：`{原名}_part{补零 max(2,段数位数)}.{ext}`（沿用输入扩展名，jpeg 保留 `.jpeg`），冲突 `(1)` 递增；`.tmp` + rename 原子写。
- **e2e**：200×900 固定高度 300 → 3 段；按份数 2 → 2 段且与首轮同名文件冲突递增为 `(1)`；中文+空格路径；页签可见。

### 7.2 R2 八类映射（增量）

| 类别         | 验证                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| 中文/空格路径 | e2e `长图 素材.png` / `输出 目录`，命名与落盘正常                                        |
| 文件被占用   | `checkReadable` 失败 → `IS_INPUT_INVALID`                                                |
| 加密文件     | `loadImage` 解码失败 → `IS_IMAGE_CORRUPT`                                                |

| 磁盘满       | 建目录/写盘 errno → `IS_WRITE_FAILED`                                                     |
| 断电恢复     | 已完成段保留、`.tmp` 残留可安全删除；重跑冲突命名 `(1)`，不覆盖既有产物                   |
